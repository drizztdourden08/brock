Add the platform bridge. A clipboard port reads and writes text, PNG and the product's own private types through main, with size caps, a checked PNG and a change flag that carries no content. A net port reads from the hosts listed in the new `product.net` and nowhere else (https only, every redirect checked, a byte cap and a content type check). `documents.copy` copies a file or folder tree with a verified copy, and `documents.rename` now moves between granted folders and across drives by copying, checking and only then removing the source. `dragOut(paths)` starts an operating system drag for paths main has checked. `pointerSupport()` reports whether pressure and coalesced pointer events are available. A rename between two different granted folders used to be refused and now works.

An upgrade worktree no longer fails lint on the files a config generator puts there. `brock prose` skips an untracked `.ai-config.json` and `.mcp.json` at the repo root, and `brockMarkdownlint` skips a `CLAUDE.md`, `AGENTS.md` or `.github/copilot-instructions.md` whose first lines say `GENERATED by ai-config`. A guide an app wrote itself has no such line and stays linted. The list lives in one place, `GENERATED_FILES` in lint-config, with a new `generated-files` export. In a monorepo, `brock sync` now also writes `.markdownlint-cli2.mjs` into an app whose `package.json` has a `lint:md` script, so `pnpm lint:md` in `apps/desktop` finds its config instead of printing help and exiting 2. The root still owns the eslint and stylelint configs, and a single app is unchanged. `create-brock` keeps that file when it scaffolds a workspace app.

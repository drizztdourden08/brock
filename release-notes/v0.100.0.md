# Brock v0.100.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- Search now finds a page by the keywords of its meta for every kind of page, and a page can declare rows of its own. A module settings page was left out of the index, and the hub page list dropped the keywords of a built-in page. Both are fixed. A new `searchRows` field in the page meta, a list of `{ label, keywords?, anchor? }`, adds one result per row: it opens the page and, with an anchor, scrolls to that element. `brock structure --check` now reports a `keywords` or `searchRows` value in a page meta that the build cannot read as a literal.
- An app review step can now set the window size. `defineReviewStep` takes `sizes`, a list of `'narrow'` (the 600 by 720 window the shell uses for its own narrow captures) or `{ name, width, height }`. The step runs once per size: the main window is resized through the review probe, which works in a hidden launch, the step runs, and the window goes back to its old size even when the step throws. The size name is added to the end of every capture and check id, so one step can capture a layout narrow and wide.

# Brock v0.100.0

Search finds pages by their keywords and by rows a page declares, and a review step can capture a screen at more than one window size.

## New

- Declare search rows on a page with `searchRows` in its meta: `{ label, keywords?, anchor? }[]`. Each row is a search result that opens the page and jumps to the element with that id.
- Capture a review step at several window sizes with `sizes` on `defineReviewStep`: `'narrow'` (the shell's 600x720) or `{ name, width, height }`. The step runs once per size, each capture and check id gets the size name, and the window goes back to its old size after the step. The window is never shown.

## Fixes

- Index the keywords of every page kind: hub pages, sub pages, tab pages, hero pages and module pages. A title match still ranks above a keyword match.
- Index the settings pages a module bucket brings.
- Report a page `keywords` value the build cannot read as a literal in `brock structure --check`, instead of skipping it.

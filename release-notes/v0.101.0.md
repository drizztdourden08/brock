# Brock v0.101.0

`brock lint` lints only what changed on a local run, the app menu puts Toolbars at the top level, and an app can fold its title bar actions into one menu.

## Upgrading

- Call `brock lint` from the app's lint script. `brock adopt` writes it for new and adopted apps. A local run lints the files changed since the merge base plus untracked files, using eslint's cache. CI and `--all` still lint the whole tree. Run `brock lint --all` to lint everything locally.

## New

- Lint cheaply. `brock lint` falls back to the whole tree when a config, tsconfig, package.json, lockfile or lint-config file changed, when git cannot tell, or above 300 files. The eslint child and `brock knip` run with a 2 GB heap ceiling, which `BROCK_LINT_MEMORY_MB` changes. A heap flag that is already set wins.
- Hide the Home menu entry with `product.menu.home: false`.
- Fold the app's title bar items into one dropdown with `titleBarMenu: { label, icon, id? }` on `BrockApp`. Shortcuts, commands and disabled reasons keep working, a status reads `Label: status`, and a menu item becomes a submenu.
- Find the Logs and Performance widgets under Widgets > Developer when developer tools are on.

## Changes

- Show Toolbars as a top-level menu right after Widgets. Its ids are unchanged, and `parent: 'section:widgets'` puts it back inside Widgets.

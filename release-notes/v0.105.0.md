# Brock v0.105.0

Brock builds on Tessera 0.68, docked toolbars get a right-click menu, an app can run a process as a job, and worktree names can carry a per-board prefix.

## Upgrading

- Expect Tessera `^0.68.0` from `brock upgrade`. Brock no longer restores focus after a context menu closes; Tessera does it now.
- Pass `appDir` to `defineBrockVitestConfig(rootDir, overrides, { appDir })` when the config sits at a workspace root. Without it, Brock uses the root when it has `brock.config.ts`, else the first workspace package that depends on brock-react.

## New

- Run a process as a job. Register it in main with `ctx.processes.define(id, { label, parse, resolve, ... })` and start it from the renderer with `jobs.runProcess(id, args)`. The renderer sends only a registered id and one value that the app's `parse` checks; the app's `resolve` builds the argv. The process runs with no shell, its output streams into the job log, and cancel kills its whole process tree. Only the main window's own frame may start one. On Windows the command must be a drive-letter `.exe` or `.com`, and `cmd`, PowerShell, `msiexec` and other command-line re-parsers need an explicit opt-in. An installer that runs with administrator rights and cannot be stopped reports `detached`.
- Right-click a docked toolbar to show its labels, move it to another side or hide it. These are the commands `toolbar.labels`, `toolbar.moveTo` and `toolbar.hide`, and the Toolbars menu gains a submenu per toolbar.
- Turn a Tessera part's menu hook into a Brock context menu with `contextMenuHandler(zone, data)`.
- Find each context menu item by `data-menu-entry` (its command id, else its label). An entry's `reason` is also its screen-reader description.
- Prefix worktree names per board with `--prefix`, `BROCK_WORKTREE_PREFIX` or `worktrees: { prefix }` in `brock.workspace.mjs`. The prefix is added once to the folder and the branch, and every worktree command takes the name with or without it.

## Fixes

- Resolve react, react-dom, zustand and Tessera from the app package when the vitest config sits at a workspace root, so a test there can import brock-react.

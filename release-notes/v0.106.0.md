# Brock v0.106.0

`brock gate` runs a cargo lane for Rust workspaces and works in repos with no Brock app, sites build static routes, and tours get an intro panel and reach nested menu entries.

## Upgrading

- Import `defineWorkspace` from `@drizztdourden08/brock-build` as well as from brock-thread.
- Expect the review tour to add a `<step>-mascot-still` check before `mascot-clear`. It waits until the mascot stops walking, up to 3 s.

## New

- Gate a Rust workspace. With a root `Cargo.toml`, `brock gate` runs a Rust comment check, `cargo fmt --check`, `cargo clippy` with warnings as errors and the 60-line and complexity-10 limits, and `cargo test`. Configure it with `gate.cargo: { enabled?, path?, clippyArgs? }`; Brock's clippy config applies when the repo has no `clippy.toml`. Only `///`, `//!` and `// SAFETY:` above `unsafe` pass the comment check.
- Run `brock gate` in a repo with no Brock app. It runs the root scripts listed under `gate.scripts` in `brock.workspace.mjs`, plus the cargo lane when there is one.
- Build static routes for a site with `build.routes: [{ path, title, description? }]` in `defineBrockSite`. Each route gets its own `index.html` with its title and description, so a static host serves it without a fallback.
- Show Tessera's tour intro panel with `intro`, `art` and `reveal` on a tour step. `art: 'product-mark'` or `{ icon }` works from a `.tour.ts` file.
- Point a tour step at a nested menu entry with `menuEntry: ['Advanced', 'Take the tour']` or a plain label. The step opens each parent menu and closes them when it ends.
- Mark a context menu entry `tone: 'danger'`.
- Use `SettingsPreviewLayout` on any page. Its preview column is a labelled landmark that F6 stops on, and so is its rows column.
- List every registered context menu with `listContextMenus()`, each with `mounted`, and register one at module scope with `defineContextMenu(id, source)`.

## Fixes

- Honour `prose: { allow }` in `brockEslint` options. It merges with the top-level `allow`, so a data name such as `claudeId` passes `local/no-slop-identifiers`.

# Brock v0.106.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- Add a cargo lane to `brock gate`. While a `Cargo.toml` with a `[workspace]` or `[package]` table sits at the repo root, the gate checks the Rust comments, then runs `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets` and `cargo test --workspace`, each reported like the other steps. Clippy runs with `-D warnings` and with the `too_many_lines` and `cognitive_complexity` lints on, held to 60 lines and a complexity of 10 by a `clippy.toml` that Brock applies when the repo has none of its own. The comment check fails any `//` or `/* */` comment in a `.rs` file with its `file:line`, and allows `///`, `//!` and a `// SAFETY:` line directly above `unsafe`. A missing cargo fails the lane with a clear message. `gate.cargo` turns the lane off (`enabled: false`), moves it (`path`) or adds clippy flags (`clippyArgs`). A repo with no Brock app can now run `brock gate`: it reads `gate` from `brock.workspace.mjs`, or runs the cargo lane alone when the root has a `Cargo.toml`.
- `defineBrockSite` takes `build.routes`, a list of `{ path, title, description? }`. After the Vite build, each route gets a copy of `dist/index.html` at `dist/<path>/index.html` with its own `<title>`, `<meta name="description">`, `og:title` and `og:description` (the Open Graph tags are changed only where the page already has them). Static hosts such as GitHub Pages serve `/privacy/` only when that file exists, so a single-page site no longer answers 404 on its legal pages. A path is letters, digits and dashes in segments split by `/`, with no leading or trailing slash and no dots; a bad or repeated path fails the build with a message naming the route. Title and description are escaped as HTML text. Asset URLs stay valid from the nested folder: absolute and base-prefixed URLs are kept, and a relative base (`./`) is rewritten to climb out of the folder. A site with no routes builds as before.
- Four small additions for Bxel. A context menu entry takes `tone: 'danger'` and passes it to the drawn item. `SettingsPreviewLayout` and its props type are exported from the barrel, so a page outside settings can use the two column preview layout. The preview column is now a `complementary` landmark named by a `label` prop (default "Preview", `previewLabel` on `SettingsLayout`, `TabDef` and `meta`), and the rows column a `region` named "Settings"; both are F6 stops. `listContextMenus()` now lists every registered menu, mounted or not, with a `mounted` flag on each, and the new `defineContextMenu(id, source)` registers a menu at module scope so a test can inspect its entries before any zone mounts.
- Pass the tour intro panel through to Tessera. A tour step gains `intro`, `art` and `reveal`, with the meaning they have on a Tessera guided step: `intro: true` draws the wide welcome panel, `art` is its picture and `reveal` runs before Tessera looks for a target that is not drawn yet. A `.tour.ts` file has no JSX, so `art` also accepts the token `'product-mark'`, which Brock turns into the product mark (the brand mark, else the product logo), and `{ icon: '<name>' }`, which becomes a Tessera icon. A `ReactNode` still works in a `.tour.tsx` file. A step without these fields is unchanged.
- A tour step can light an entry in a submenu. `target: { menuEntry }` takes a path, `{ menuEntry: ['Advanced', 'Take the tour'] }`, and a plain label is now searched for in the submenus too. Brock opens each parent submenu in order with a click, as a pointer would, before the step lights the entry, and the submenus close with the menu when the step ends. An entry that is not there leaves the step centred.

## Fixes

- @drizztdourden08/brock-core@0.106.0
- Honour `prose.allow` in `brockEslint`. Words listed under `prose: { allow }` now reach `local/no-slop-identifiers` and the slop rules, joined with any top-level `allow`, so a field name such as `claudeId` can be allowed in either shape.
- The review tours wait for the walking mascot to stop before they check that it keeps off the lit part. The wait reads the mascot's position until it holds still for a few polls, up to 3 seconds, and the step fails with the reason when it never stops. It replaces the single fixed 700 ms pause, which a long walk to a page-sized hole outlasted. - @drizztdourden08/brock-core@0.106.0

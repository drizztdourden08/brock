# Brock v0.106.2

Brock's own screen scrollers keep room for the scrollbar, so content no longer reflows when the scrollbar comes and goes.

## Fixes

- Keep a stable scrollbar gutter on Brock's own scrollers: the page body, the info card, a hub with no nav, a plain hub page and the release notes panel. The scrollbar width stays reserved, so a responsive layout such as a lobby no longer flips between one and two columns. The scrollers inside Tessera's `ScreenPage` and `SideNavLayout` get the same default in a coming Tessera release.

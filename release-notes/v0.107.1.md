# Brock v0.107.1

Brock moves to Tessera 0.78, so every screen scroller keeps room for the scrollbar.

## Upgrading

- Bump `@drizztdourden08/tessera` to 0.78 or later. brock-react now needs it.

## Fixes

- Keep a stable scrollbar gutter on every screen scroller. Brock's own scrollers use Tessera's `ScrollArea gutter="stable"` in place of the CSS rule from 0.106.2, and Tessera's `ScreenPage` and `SideNavLayout` content use a stable gutter by default. Content no longer reflows when a scrollbar comes and goes.

# Brock v0.108.0

A dev start does far less work: linked Brock packages are pre-bundled, unchanged main and preload bundles are reused, and an idle sync is near instant. A failed interface load now shows its error at once, and elevated installer jobs can be cancelled.

## Upgrading

- Bump `@drizztdourden08/tessera` to 0.80 for the faster start. 0.78 still works.
- Set `build.optimizeDeps.liveBrock: true`, run `brock dev --live-brock` or set `BROCK_LIVE_BROCK=1` if you edit linked Brock source and want hot reload. The default now pre-bundles it.

## Changes

- Pre-bundle the Brock packages an app links from outside its workspace, such as a Brock checkout linked with `link:`. A dev start loads a few chunks instead of about 1,900 source files. The optimizer hash carries a stamp of those packages' files, so a branch switch or an edit there re-bundles them on the next start.
- Cancel an elevated installer job (`elevate: 'installer'`) by default. Cancel tries the normal stop, then a forced stop after 2 s. If the installer exits in time, the outcome is `cancelled`. If it still runs 3 s later, the job stops waiting and ends as `detached` with "The installer keeps running on its own. Brock stopped waiting for it." Its streams and log file are closed. `cancellable: false` still turns cancel off.

## Fixes

- Stop a dev app at once when the interface fails to load, for example on a module error after a Tessera mismatch. The splash shows the error with Open logs, Retry and Quit instead of waiting 120 s. Launch, dev, build and start also stop with one clear line when the app's Tessera does not fit what brock-react needs, and `brock doctor` checks the same.
- Reuse the main and preload bundles on a dev start while nothing they depend on changed: their files, the package manifests they resolve through, the config and what it imports, the mode, its `.env` files, the environment and the build options. That saves 2 to 4 s on a warm start.
- Seed a new worktree's Vite dependency cache from `~/.brock/cache/vite-deps` when another worktree with the same lockfile made one.
- Sync inside the launcher process, and run the cold-start Tessera guide after the app starts. `brock sync --if-stale` on an app that is already in sync checks a few file stamps and returns in well under a second.
- Build against Tessera 0.80, whose `tokens.css` is one flat pre-built file.

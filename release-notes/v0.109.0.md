# Brock v0.109.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- A context can carry a label. `contexts.set('session', { active, data, label: 'Sunday run' })` puts the label after the title of every widget bound to that context, so a Players widget reads Players, Sunday run, docked, floating and popped. A changed label updates the titles, and no label keeps the plain title.
- Layout presets grow. `defineLayoutPreset({ revision })` (a number, 1 when unset) versions the default layout: a profile stores the revision its saved layout came from, and when the preset is newer Brock shows one toast with Reset, where closing it keeps the profile's layout and stores the new revision. `onRevision: 'apply'` resets to the new layout at load instead of asking. A cell can now be a column of stacked panes, `{ column: ['players', 'hints'], sizes: [0.6, 0.4] }`, and a row written `{ cells: [...], under: 'main' }` sits under the main view only instead of across the full width. `toast` takes an `onClose` option.
- A tour step can now reset the screen it shows with `reset: true`, or `reset: { search, filters, tab, selection }` for some parts, so a tour always starts from a clean view. Brock clears the matching screen state before it lights the target and waits one frame. The hub page search, the hub tab, the window section and the settings search are cleared for you. `useScreenState` takes an optional third argument naming the part a key holds, and the new `useTourReset(handler)` hook covers state kept outside that store. A screen with nothing to reset is left alone. New shell targets: `{ shell: 'primary' }` (the primary button of the open screen header), `{ shell: 'back' }` (the Back button of a sub page), `{ shell: 'menu-panel' }` (the open root app menu panel) and `{ shell: 'rail', entry: 'Games' }` (one sidebar entry of the open screen by its label).

# Brock v0.109.0

Layout presets get revisions and column cells, widgets can show a context label in their title, and tours can reset a screen and light more parts of the shell.

## New

- Version a default layout with `defineLayoutPreset({ revision })`, a number that is 1 when unset. A profile stores the revision its saved layout came from. When the preset is newer, Brock shows one toast with Reset; closing it keeps the profile's layout and stores the new revision. Set `onRevision: 'apply'` to reset to the new layout at load without asking.
- Stack panes in a layout cell with `{ column: ['players', 'hints'], sizes: [0.6, 0.4] }`. A row written `{ cells: [...], under: 'main' }` sits under the main view only, not across the full width.
- Label a context with `contexts.set('session', { active, data, label: 'Sunday run' })`. Every widget bound to it shows the label after its title, docked, floating and popped, so a Players widget reads Players, Sunday run. A changed label updates the titles, and no label keeps the plain title.
- Reset the screen a tour step shows with `reset: true`, or `reset: { search, filters, tab, selection }` for some parts. Brock clears the hub page search, the hub tab, the window section and the settings search for you. Name the part a key holds with the third argument of `useScreenState`, and use the new `useTourReset(handler)` hook for state kept outside that store.
- Light more of the shell in a tour step: `{ shell: 'primary' }` for the primary button of the open screen header, `{ shell: 'back' }` for the Back button of a sub page, `{ shell: 'menu-panel' }` for the open app menu, and `{ shell: 'rail', entry: 'Games' }` for one sidebar entry by its label.
- Pass `onClose` to `toast`.

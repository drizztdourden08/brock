# Brock v0.109.1

Context labels use Tessera's muted sublabel, `brockEslint` finds its root from the config file, and old launch files are cleaned up.

## Upgrading

- Bump `@drizztdourden08/tessera` to 0.82 or later. brock-react now needs it for the widget sublabel.

## Fixes

- Show a context label as Tessera's `sublabel`, not as text added to the title. A Players widget bound to a context labelled Sunday run keeps the title Players and shows Sunday run after it as a muted label with its own ellipsis, docked, floating or popped. A clipped title shows in full in a tooltip.
- Find `brockEslint`'s root from the eslint.config file that called it when `rootDir` is not passed, then from the nearest folder above that holds an eslint.config file. Running ESLint from a subfolder such as `apps/web` now recognises `@kind verbatim` and data files. A `rootDir` you pass still wins.
- Remove old launch files from the user data folder. Each `--user-data` profile left a `launch-bridge.data-<hash>.json` file behind. On start the bridge now removes, in the background, those whose profile folder is gone, that no running instance uses and that are older than five minutes. The plain `launch-bridge.json` is never touched.

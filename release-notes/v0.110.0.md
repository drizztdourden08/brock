# Brock v0.110.0

An assistant or any other caller can now drive a Brock app through stable APIs: commands report why they are off, widgets and toolbars have facades, settings have a catalogue, open confirms can be answered, and the app can restart with a one-shot handoff.

## Upgrading

- Await `commands.run` and read `.ok` if you used its result. It returned a boolean and now returns a promise of `{ ok: true }` or `{ ok: false, why, reason }`.

## New

- Say why a command is off with `CommandDef.reason`, a function that returns a string or null. Attach plain app data with `CommandDef.meta`; `commands.list()` passes it through. `commands.describe(id)` returns `{ enabled, reason, checked }`. `commands.run(id)` refuses a command whose `when` is false (`gated`) or whose `reason` returns a string (`disabled`), awaits a `run` that returns a promise, and reports the outcome. `CommandTrigger` gains `'assistant'`. A command with a reason shows greyed out in the menus.
- Drive widgets with `widgets.list()`, `dock`, `float`, `resize`, `focus`, `presets`, `applyPreset`, `registerPresets` and `subscribe`. Each snapshot gives visibility, placement, side, size, pane index, floating rect, popped state and context. Drive toolbars with `toolbars.list()`, `show`, `hide`, `moveToSide`, `labels`, `reset` and `subscribe`. An unknown id or a bad side or size throws an error that names the valid ones.
- List every settings tab, section and item with `settingsCatalog()`, each with its control, choices and value. Password values are left out. `settings.set(key, value)` changes an app setting after checking it and returns `{ ok }` with a reason when it refuses.
- List the app's screens with `nav.routes()`, with titles and sections. Hidden and dev-only entries are left out.
- Read the open confirm dialog with `dialogs.current()` and answer it with `dialogs.answer(choice)`. An unknown choice leaves the dialog open.
- Restart the app with `restartApp({ handoff, window })` from brock-electron. The next boot reads the handoff once with `takeRestartHandoff()` in main or `api.takeRestartHandoff()` in the renderer. It lives in a private file in the user data folder, is limited to 64 KB, expires after 60 s and is deleted on first read. It is a short handoff, not a secret store.

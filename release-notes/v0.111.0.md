# Brock v0.111.0

The main process can grant a temp folder it made itself, even though temp folders sit under AppData on Windows.

## New

- Make a temp folder with `ctx.documents.createTempFolder(prefix?)` on the main side. It runs `fs.mkdtemp` under the system temp folder and returns the real path. `allowFolder` then accepts that folder, or one inside it, even though it sits under AppData. Only folders made this way in the current session pass: the list lives in memory, a link is judged by its target, and no flag or environment variable widens it. Every other folder check still applies. `forgetTempFolders()` empties the list without deleting anything. The renderer cannot reach either call.

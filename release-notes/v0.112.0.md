# Brock v0.112.0

Each settings row can be reset on its own.

## Changes

- Reset one settings row at a time. When a settings tab has defaults and an item is not locked, its row gets `changed` (the value differs from its default) and `onReset`, which restores only that key, nested keys included, through the same patch as any other edit. A locked item, an item with no default, and the rows of a source section get neither. The section reset stays as it was.

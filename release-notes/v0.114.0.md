# Brock v0.114.0

The platform bridge lands: clipboard, verified copy and move, network reads from listed hosts and dragging files out. Toolbars get per-item visibility and columns on Tessera 0.88, widget rows can keep keyboard focus, and the full-tree lint no longer runs out of memory.

## Upgrading

- Bump `@drizztdourden08/tessera` to 0.87 or later. brock-react now needs it, and Brock builds against 0.88.
- List the hosts an app may read from in `product.net` before calling `net.read`. Nothing is reachable without it.

## New

- Read and write the clipboard through main: text, PNG and the product's own private types (`application/x-<productId>-<name>`), with size caps, a checked PNG and a change flag that carries no content. A watch belongs to the window that made it and ends when that window closes.
- Copy a file or folder with `documents.copy`, and move between granted folders or across drives with `documents.rename`. Both make a hashed, staged copy. The source is removed only after the copy is verified, and a file that changed after it was copied stays in place and is reported.
- Read from the hosts in `product.net` with `net.read(url, { maxBytes })`: https only, every redirect checked, a byte cap and a content type check. A body cut short fails.
- Start an operating system drag of checked files with `dragOut(paths)`. Links are refused, inside a dragged folder too. `pointerSupport()` reports whether pressure and coalesced pointer events reach the renderer.
- Hide single toolbar items and choose 1, 2 or automatic columns for a side toolbar. `defineToolbar` takes `items: [{ id, label }]`, and the toolbar right-click menu gets Items and Columns. Both are saved in the toolbar layout and reach `render(slot)` as `slot.hiddenItems` and `slot.columns`. `toolbars.items(id, hiddenIds)` and `toolbars.columns(id, n)` set them from code.
- Let a widget row keep keyboard focus after a click: spread `keepsWidgetFocus()` on a row that handles F2, the arrows or Delete itself. The README explains the focus guard and how a test focuses a widget row with the keyboard.

## Fixes

- Run the full-tree `brock lint` in batches of 1000 files, one process after another, each with a 4096 MB heap ceiling. Memory no longer grows with the tree, which fixes the out of memory crash in CI. The exit code is the worst of all batches. A changed-files run stays one process at 2048 MB. `BROCK_LINT_BATCH_SIZE`, `BROCK_LINT_MEMORY_MB` and `BROCK_LINT_STATS=1` tune and report it.
- Make `worktree finish` and `worktree remove` work on Windows when `node_modules` holds paths past 260 characters. Git runs with long paths on, ignored folders are deleted first without following links, and a locked file is reported instead of hanging.

# Brock v0.114.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- Add the platform bridge. A clipboard port reads and writes text, PNG and the product's own private types through main, with size caps, a checked PNG and a change flag that carries no content. A net port reads from the hosts listed in the new `product.net` and nowhere else (https only, every redirect checked, a byte cap and a content type check). `documents.copy` copies a file or folder tree with a verified copy, and `documents.rename` now moves between granted folders and across drives by copying, checking and only then removing the source. `dragOut(paths)` starts an operating system drag for paths main has checked. `pointerSupport()` reports whether pressure and coalesced pointer events are available. A rename between two different granted folders used to be refused and now works.
- A user can hide single toolbar items and choose how many columns a vertical toolbar uses, and the app moves to Tessera 0.87, which is now the lowest supported version. Nothing else changes. - `defineToolbar` takes `items`, a list of `{ id, label }`. The toolbar right-click menu lists them under Items, one check each, and a toolbar on the left or right also gets Columns (1 column, 2 columns, Auto). Both choices are saved in the toolbar layout and reach `render(slot)` as `slot.hiddenItems` and `slot.columns`; pass them to Tessera's `Toolbar` as `hiddenItems` and `columns`. - New commands `toolbar.item` and `toolbar.columns`, and the facade calls `toolbars.items(id, hiddenIds)` and `toolbars.columns(id, count)`. `toolbars.list()` gains `hiddenItems` and `columns`. - A toolbar ruled out by `when` leaves no bar, no border and no empty lane, and the saved layout is not changed.
- Let a widget row keep keyboard focus after a click. An element with `data-widget-keeps-focus`, or inside one, is exempt from the widget focus guard, so a row that handles F2, the arrows or Delete itself keeps its focus. `keepsWidgetFocus()` returns the attribute to spread on the element and `WIDGET_KEEPS_FOCUS` is its name. The README and the architecture guide now explain why the guard exists and how a test focuses a widget row with the keyboard.

## Fixes

- `brock lint` on the whole tree now runs eslint in batches of 1000 files, one process after the other, and exits with the worst code of all batches. The memory of a run no longer grows with the tree, which fixes the out of memory crash of the full-tree lint in CI. Each batch gets a 4096 MB heap ceiling (it was 2048 MB for the whole run), and each keeps its own cache file. A changed-files run and a run on named files stay one process at 2048 MB. `BROCK_LINT_BATCH_SIZE` sets another batch size, `BROCK_LINT_MEMORY_MB` and a heap flag in `NODE_OPTIONS` still win, and `BROCK_LINT_STATS=1` prints each batch's peak memory.
- Make `worktree finish` and `worktree remove` work on Windows when `node_modules` holds paths past 260 characters. Git runs with long paths on, the ignored folders are deleted first through Node (links are removed, never followed, and nothing outside the worktree is touched), and a locked file is retried and then reported instead of hanging.

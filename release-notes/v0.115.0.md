# Brock v0.115.0

A widget's `order` now also sets its default place in a dock column, whichever widget opens first.

## Changes

- Place a newly docked widget by its `order`. When Brock opens a widget onto a side that already holds others, it puts the widget after the last one with the same or a lower order, so a View widget with order 2 sits under Project with order 1 whichever opens first. A lower order sits higher in a column, or further left on the top and bottom sides. Widgets with no order keep open order, after the ordered ones. Only the new widget is placed: panes already docked, a layout the user arranged and a layout preset that names its widgets are never reordered.

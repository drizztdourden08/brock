# Brock v0.115.2

A docked widget now gets the exact width asked for, also when the other side holds a widget.

## Fixes

- Give a docked widget the exact width from `widgets.dock(id, { size })` and `widgets.resize(id, px)`. Before, the size was a share of the window that Tessera applied to the inner side only, so a right widget asked for 300 px could end near 230, and the left one shrank when the right one was docked. Brock now measures the real stage, sets the width and puts the other side back to its pixels. Both calls return `{ size, reason }`: the width the widget ended with, and a plain sentence when the 5% to 90% edge limit changed the request.

# Brock v0.115.3

`worktree remove` no longer fails on a folder that vanished mid-delete, and Brock builds against Tessera 0.89.1.

## Fixes

- Skip a path that is already gone at every step of `worktree remove`. An ignored folder inside another one used to fail with "ENOENT lstat" once its parent was deleted. The ignored folders are now listed once, children of a listed parent are dropped, and the removal goes on to `git worktree remove` and prune. The check that a path stays inside the worktree is unchanged.
- Build against Tessera 0.89.1, whose dock column corner handle has a 24 by 24 hit area, so widget controls near it pass the axe target size check. Bump Tessera to 0.89.1 for the fix; 0.87 still works.

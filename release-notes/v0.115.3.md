# Brock v0.115.3

One paragraph for the people who use Brock: what this release changes for them.

## Fixes

- @drizztdourden08/brock-build@0.115.3
- @drizztdourden08/brock-core@0.115.3
- Build against Tessera 0.89.1. Its dock column corner handle has a 24 by 24 hit area, so widget controls near it pass the axe target size check. Apps can bump Tessera to 0.89.1 for the fix; 0.87 still works. - @drizztdourden08/brock-core@0.115.3
- Fix `worktree remove` failing with "ENOENT lstat" when an ignored folder was already gone because its parent was deleted first. A vanished path is now skipped at every step of the delete, the ignored folders are listed once with children of a listed parent dropped, and the removal goes on to `git worktree remove` and prune. The check that a path stays inside the worktree is unchanged.

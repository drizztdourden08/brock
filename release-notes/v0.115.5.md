# Brock v0.115.5

The controller drawing shows its button glyphs again, and typed drag and drop no longer goes stale.

## Fixes

- Show the button glyphs on the pad drawing in the Live input box when no glyph source is registered. The face buttons, shoulders, triggers, View, Menu and Xbox draw Tessera's own input icons in place of empty rings, as the Buttons list does. A glyph image from `registerGlyphSource` still wins when one answers.
- Read a drag source's `disabled` and `payload` when the drag starts, so a source that becomes disabled stops dragging and a drag carries the payload of the latest render. A drop target reads `onDrop`, `canDrop`, `feedback` and `index` live the same way.
- Cancel the browser's own drag for an image, link or selected text inside a drag source, so it no longer cancels the typed drag. File drops into a target that accepts `dnd.files` are not touched.

# Brock v0.115.5

One paragraph for the people who use Brock: what this release changes for them.

## Fixes

- @drizztdourden08/brock-core@0.115.5
- @drizztdourden08/brock-lint-config@0.115.5
- @drizztdourden08/brock-thread@0.115.5
- @drizztdourden08/brock-build@0.115.5
- @drizztdourden08/create-brock@0.115.5
- Fix typed drag and drop going stale. A drag source now reads `disabled` and `payload` when the pointer goes down and when the drag starts, so a source that becomes disabled stops dragging and a drag carries the payload of the latest render. A drop target reads `onDrop`, `canDrop`, `feedback` and `index` live in the same way. A drag source also cancels the browser's own drag (`dragstart`) for an image, link or selected text inside it, so that drag no longer cancels the typed pointer drag. Native file drops into a target that accepts `dnd.files` are not touched. - @drizztdourden08/brock-core@0.115.5
- The pad drawing in the Live input box shows the button glyphs again when no glyph source is registered. The face buttons, shoulders, triggers, View, Menu and Xbox now draw Tessera's own input icons in place of empty rings. A glyph image from `registerGlyphSource` still wins when one answers.
- @drizztdourden08/brock-port-kit@0.115.5

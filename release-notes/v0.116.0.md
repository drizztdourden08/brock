# Brock v0.116.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- A page header can now show a secondary button next to the primary one. Declare `header: { secondary: { label, icon?, open }, primary, search }` in a page's meta, or pass `secondary={{ label, icon, onClick }}` to `PageActions`. It has the same shape as `primary`, draws as a secondary Tessera button just left of the primary button, and is absent when unset. The tour target `{ shell: 'primary' }` still lights the primary button only.

## Fixes

- `brock structure --check` accepts the widget meta fields added in 0.113.0: `contexts`, `when`, `empty` and `prefs`, and `when` on a widget kit. Before, a widget that used one of them was reported as having an unknown field. - @drizztdourden08/brock-core@0.116.0 - @drizztdourden08/brock-lint-config@0.116.0 - @drizztdourden08/brock-thread@0.116.0
- Sigstore and TUF signature checks work in the Electron main process again. Electron has no default digest for EC keys, so `crypto.verify(null, ...)` failed there while it works in Node. Brock now gives that call the SHA-256 digest OpenSSL would pick, for P-256, P-384 and P-521 keys only; every other call goes through untouched. Turn it off with the `ecNullDigestShim: false` bootstrap option or `BROCK_NO_EC_DIGEST_SHIM=1`. - @drizztdourden08/brock-core@0.116.0

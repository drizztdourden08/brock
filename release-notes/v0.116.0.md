# Brock v0.116.0

Development can now stay on the machine, from checks to releases. Fresh worktrees reuse a shared build cache, and the main process can no longer pull in renderer code by accident.

## Upgrading

- An app whose main process imports renderer code now fails to build. Cut the import, or list it in `mainProcess.allow`.

## New

- Run the repo's checks locally with `brock ci`. It reads `.github/workflows/ci.yml` and runs the same jobs and steps in a temporary worktree at a commit, with an offline install. Each run writes a check-run record to `~/.coord/ci/<project>/` with a log per step. `brock ci lint` runs one job or step by name, and `--pr PR-n` checks the head of that pull request.
- Merge a pull request with `pr merge --local PR-n`. It merges only when the newest check run of the head commit passes every required step.
- Release with `brock release --local`. It cuts `release/local-<version>`, runs `changeset version`, waits for the release note, and packs every changed package into `~/.coord/releases/<project>/<channel>/<version>/` with `notes.md` and `release.json`. It opens a local pull request and never merges.
- Share compiled packages and Electron binaries across every project and worktree with the new `@drizztdourden08/build-cache` package. `worktree create` starts `brock prewarm`, so the first launch finds main, preload and the renderer dependencies ready. `brock cache list` shows the entries. Argus prunes the cache; Brock never deletes from it.
- Fail the main process and preload builds when they reach renderer-only code. The error prints the import chain. Add packages or folders with `mainProcess.forbid` in `brock.config.ts`, and exceptions with `mainProcess.allow`.
- Show a secondary button in a page header with `header.secondary` in the page meta, or `secondary` on `PageActions`.
- Build without syncing first with `brock build --no-sync`.

## Fixes

- Verify Sigstore and TUF signatures in the Electron main process. Electron has no default digest for EC keys, so Brock passes the one OpenSSL would pick. Turn it off with `ecNullDigestShim: false` or `BROCK_NO_EC_DIGEST_SHIM=1`.
- Open a bridge link on Windows without freezing the process. The check that the discovery file is private now runs off the event loop and caches files it already accepted.
- Remove worktrees safely when they hold links. Every delete removes links as links first and stays inside the folder it owns, so a junction can never lead a delete into the main checkout.
- Accept the widget meta fields `contexts`, `when`, `empty` and `prefs` in `brock structure --check`.
- List `brock ci` and `pr merge --local` in `brock help`.

# Brock v0.116.1

New worktrees start from a shared install and shared builds, so they are ready in seconds. Widgets gain file drops, commands gain widget scope and two-key bindings, and the OS integration and the bridge check no longer start child processes.

## Upgrading

- Declare `koffi` in the app. The OS integration and the bridge check now call Windows directly through it, and the app bundle loads it from the app's own `node_modules`. `brock upgrade` adds it to an app that uses `brock-electron`; run `pnpm install` after.
- Use `@drizztdourden08/standards` 0.14 or later. The Brock lint preset needs it for the knip preprocessor, and new apps start on it. Every test file must carry exactly one of critical, standard or e2e (`local/test-has-one-tag`).
- Expect one more build in a worktree. Build records from an older Brock read as a miss once, and the pre-bundle cache moves to a new layout.

## New

- Start a worktree from another checkout of the same lockfile. `worktree create` links `node_modules` and a shared copy of the package store, and copies the build records and generated outputs, instead of installing and building again. `--no-clone` runs `pnpm install` as before. On Archipelia the create took 1.4 s instead of two minutes after a one-time store copy.
- Share builds across worktrees through the build cache. The dev main and preload bundles, the renderer pre-bundle, the Electron binaries and the SDL3 addon (the verified archive and the installed files) each have an entry kind. A cache miss logs why and builds as before. `brock prewarm` and `brock dev` restore a hit, and `worktree launch` restores the main and preload builds before `electron-vite dev`.
- Add a file drop zone to a widget with `defineWidget({ drop })`. It takes an OS drop or an app drag of paths, filters by extension, caps the files per drop and reads them as bytes or text. `useFileDropZone` gives any element the same rules. Add `dnd.paths`, `useWindowFileDrop`, `useFileListDrag` and `dnd.indexAmong(selector, axis)` for path drops and tab-strip inserts.
- Show a drag ghost with `preview: { label, count? }` on `dnd.source`, `useDragSource` and `useFileListDrag`. A count of 0 hides the badge.
- Limit a command to a widget with `CommandDef.widget`. It fires only while that widget is the active one. Bind one command to many keys with `bindings: [{ args, chord }]`, use chords such as `Space+B`, and open the Keyboard page at a command with `openKeymapAt`.
- Scope the palette with `palette.pick`. A pick takes `scopes` and an opening `scope`, Tab moves between scopes, and `group` titles result groups.
- Supply a bucket header by file with `src/screens/<bucket>/<bucket>.header.tsx`, with an optional `actions` export. `brock structure` checks the file name and place. The lint stack treats it as a screen file.
- Show a settings row only while another setting has a value with `visibleWhen: { key, equals }` or `notEquals`. A hidden row keeps its stored value.
- Pick a destination folder with `DocumentFolderField`, backed by the new `documents.canWrite(folder)` dry run that writes and grants nothing.
- Set the boot task time limit with `--boot-timeout=<seconds>`. The default is 20 s, or 60 s for an automated or headless launch.
- Read `useFocusMode()` and keep widgets and toolbars visible in focus mode with `layout.focusKeep`.
- Run `brock ci --here` as a cheap gate for `pr merge --local`, and `replay plan` and `replay run --go` to move local work to GitHub on the owner's go.
- Run `brock doctor` to check the app: package versions, `link:` targets, generated files and undeclared imports. It exits 1 on a problem.
- Export `recoveryDir`, `listRecoverySnapshots` and `SNAPSHOT_EXT` from `brock-electron/node`, so an e2e test can poll for the first recovery snapshot.

## Changes

- Check local runs faster. A step that passed for the same git tree is reused, every step has a time limit, and tests cover only files changed since the merge base. `brock lint` reads `BROCK_LINT_MODE` and compares with the local default branch when `origin/HEAD` is behind.
- Key the build reuse of a linked Brock by the content of its build sources and ignore line ends and generated launch files, so a fresh worktree of the same commit hits the cache.
- Write the store files atomically. `readJson` logs a parse error, keeps the bad text in a `.corrupt-<time>` file and returns the fallback.
- Grant a dropped path only from a drop in that window. `document:vetDrop` takes one use of a tracked path for 15 seconds, so page script can no longer ask for a folder grant.
- Apply the saved stick calibration and dead zone to every controller report. `rawSticks` carries the raw values.
- Start new apps with a `.gitattributes` of `* text=auto eol=lf`. `brock adopt` writes it when none exists.
- Run `replay` with lockfile checks. It regenerates consumer lockfiles and refuses to push a lockfile that points at `file:` or `.coord/localpkg`.
- Start `gh` only through the guarded wrapper, so `brock release` refuses it in local mode.
- Run thread verbs through the project's own `brock-thread` when the global brock finds no project `brock-build`.

## Fixes

- Compare the bridge file owner and access entries by SID. Long account names, localized accounts and elevated apps are no longer refused by mistake.
- Make Sigstore verify work in Electron. The EC digest shim now passes a public `KeyObject` through as it is.
- Show the controllers that are plugged in at start, find display settings in search, without a replug, and fix positional capture so an idle pad can be captured.
- Fix `useHoldReleased`, which read the capture hold backwards.
- Load a restored renderer pre-bundle from the worktree's own package store, so Vite no longer refuses files outside its allow list.
- Stop `brock lint` reusing a stale result for a file whose imported types changed.
- Stop knip reporting a bare esbuild script entry such as `esbuild src/index.ts`.
- Pass `settings.defaults` to settings rows, so a changed dot and reset action show on standard rows and in search.
- Skip the review volume focus probe in a window without focus.
- Stop `worktree create` and `upgrade` aborting on the pnpm purge question. A failed install now stops with the folder and the pnpm exit code.

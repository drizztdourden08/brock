# Brock v0.117.1

One paragraph for the people who use Brock: what this release changes for them.

## Fixes

- @drizztdourden08/brock-build@0.117.1
- @drizztdourden08/brock-core@0.117.1
- The Brock stylelint preset skips the generated `.brock/` folder, as the ESLint preset already does. `brock sync` writes `.brock/palette.css` with a plain header, which `comment-pattern` flagged once standards 0.14.9 linted every git-listed style file.
- `upgrade` installs without a frozen lockfile after the migrations run. A migration that adds a dependency (such as `koffi-dependency` in 0.117.0) changes `package.json`, so the old frozen install failed with `ERR_PNPM_OUTDATED_LOCKFILE`. The new lockfile is part of the upgrade commit. - @drizztdourden08/build-cache@0.117.1
- @drizztdourden08/brock-electron@0.117.1
- @drizztdourden08/brock-react@0.117.1
- @drizztdourden08/build-cache@0.117.1

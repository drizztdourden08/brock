# Brock v0.117.1

Two fixes for apps on 0.117.0. Stylelint no longer flags the palette file that `brock sync` generates, and `brock upgrade` no longer fails when a migration adds a dependency.

## Fixes

- The Brock stylelint preset skips the generated `.brock/` folder, as the ESLint preset already does. `brock sync` writes `.brock/palette.css` with a plain header, which `comment-pattern` flagged once standards 0.14.9 linted every git-listed style file.
- `upgrade` installs without a frozen lockfile after the migrations run. A migration that adds a dependency (such as `koffi-dependency` in 0.117.0) changes `package.json`, so the old frozen install failed with `ERR_PNPM_OUTDATED_LOCKFILE`. The new lockfile is part of the upgrade commit.

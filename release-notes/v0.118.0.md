# Brock v0.118.0

Two new commands and a set of app review fixes. `brock add mobile` sets up the Android target, and `pr push` can now push the base branch from the main checkout. The app review now fits single-profile apps, apps with workspaces and buckets reached through the settings gear.

## New

- `brock add mobile` (or `brock add android`) wires Capacitor into an app. Mobile is a target, not a module, so it runs the same steps as `brock platform add mobile` and installs no package. It then prints the next steps: `<app> mobile build` for the APK and `<app> mobile keystore` for the release keystore. The `--local` flag does not apply and is ignored with a note.
- `pr push` pushes the base branch from the main checkout, for every repo of the family. Run it with no name on the base branch there, or name the base branch. It fetches origin first, refuses a diverged base with the commit count of each side, never forces, and states the count, the range and the commit subjects before it pushes. A base branch checked out in a worktree is still refused.

## Fixes

- The app review fits single-profile apps. It expects the document title the title bar shows and drops the Profiles menu entry under `product.singleProfile`.
- The app review counts the home bucket and the settings bucket as reachable through Home and the settings gear, skips a bucket with no route at all, and checks full screen on the About screen.
- The app review reads the saved widget layout where the app writes it. With a workspace active, the layout lives under that workspace, so `pop-out-bounds-stored` and `pop-out-restart-restores` failed on apps with workspaces. The checks now read the active workspace's layout.
- `floating-widget-resizes` expects the floating widget's edge to snap to the main view's edge when the grown edge lands within the float snap distance (10 pixels).

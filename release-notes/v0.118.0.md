# Brock v0.118.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- `brock add mobile` now wires Capacitor into an app. Mobile is a target, not a module, so the command runs the android platform steps, the same as `brock platform add mobile`, and installs no package. After it succeeds it prints the next steps: `<app> mobile build` for the APK and `<app> mobile keystore` for the release keystore. The `--local` flag does not apply and is ignored with a note.
- `pr push` now pushes the base branch from the main checkout, for every repo of the family. Run it with no name on the base branch there, or name the base branch. It fetches origin first, refuses a diverged base with the commit counts of each side, never forces, and states the count, the range and the commit subjects before it pushes. A base branch checked out in a worktree is still refused.

## Fixes

- @drizztdourden08/brock-core@0.118.0
- The app review reads the saved widget layout where the app writes it. With a workspace active, the layout is saved under that workspace in `workspaces`, not as the profile's `widgetLayout`, so `pop-out-bounds-stored` and `pop-out-restart-restores` failed on apps with workspaces even though the bounds were saved. The checks now read the active workspace's layout. `floating-widget-resizes` now expects the floating widget's edge to snap to the main view's edge when the grown edge lands within the float snap distance (10 pixels). The resize was right; the check ignored the snap.
- The app review now fits single-profile apps and buckets reached through the settings gear. It expects the document title the title bar shows, drops the Profiles menu entry under `product.singleProfile`, counts the home bucket and the settings bucket as reachable through Home and the gear, skips a bucket with no route at all, and checks full screen on the About screen. - @drizztdourden08/brock-core@0.118.0

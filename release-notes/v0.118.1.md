# Brock v0.118.1

One app review fix for 0.118.0, and Brock now builds against Tessera 0.102.0.

## Fixes

- The app review checks full screen on a registered screen drawn in a screen layer: settings, then profiles, then the first other one. In 0.118.0 it opened About, which draws its own layer, so `cluster-fullscreen` never found the square screen and waited out its 30 second ceiling.

# Brock v0.119.0

Brock no longer flashes console windows on Windows. Every child process it starts hides its window, and a new lint rule keeps it that way in every app.

## Upgrading

- The new `brock/spawn-hides-window` rule is an error. Add `windowsHide: true` to the options of each `spawn`, `spawnSync`, `exec`, `execSync`, `execFile`, `execFileSync` or `fork` call from `node:child_process`. A call with no options gets `{ windowsHide: true }` as its options argument.

## New

- The `brock/spawn-hides-window` lint rule. It flags a child process call that does not pass an options object with `windowsHide: true`.

## Fixes

- Every child process Brock starts hides its console window on Windows. This covers `brock upgrade`, the launcher, the local CI, the thread verbs, the build steps and the module installers. Vite's `net use` probe runs under a hidden parent too, so bursts of console windows no longer open on the desktop.

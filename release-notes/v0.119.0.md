# Brock v0.119.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- New rule brock/spawn-hides-window. A call to spawn, exec, execFile or fork from node:child_process must pass an options object with windowsHide: true, so no console window opens on Windows.

## Fixes

- Every child process Brock starts now hides its console window on Windows. Bursts of console windows no longer open on the desktop.

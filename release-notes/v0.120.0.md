# Brock v0.120.0

The SNES plugin's `copyAssetBlob()` can copy an asset blob that is not named after the ROM.

## New

- `snes.copyAssetBlob({ asset: 'ct_assets.dat' })` names the source blob in the app data `assets` folder. The worktree copy keeps the ROM stem name. Without `asset`, the step looks for `<ROM stem><assetExtension>` as before.

## Fixes

- When no pre-extracted blob is found, the log names the blob and the folder it checked. It no longer says the first launch extracts it, which was wrong for ports with no in-app extraction.

# Brock v0.120.1

A visible launch shows the app's main window again on Windows. Brock 0.119.0 and 0.120.0 started Electron with its window hidden.

## Changes

- The `brock/spawn-hides-window` rule accepts any explicit `windowsHide` value. Pass `true` for a console tool, and `false` only for a GUI app whose window must show. A call with no `windowsHide` key still fails.

## Fixes

- A visible launch shows the main window on Windows. Brock 0.119.0 started the Electron binary with `windowsHide: true`, so Windows kept the first window hidden and the launch flashed and showed nothing. The Electron launch and the bridge that starts another app now pass `windowsHide: false`. Console tools stay hidden.

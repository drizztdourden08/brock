# Brock v0.122.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- `aspectRatioValue` takes `keepOrientation`. With it set, 'auto' and 'screen' keep a portrait window or screen portrait (width below height) instead of turning it to landscape. The result is still clamped to the limits, so a very tall screen stops at `limits.min`. `detectViewportRatio` and `detectScreenRatio` take the same flag as a third argument.
- `lockOrientation(mode)` from `brock-display/renderer` turns and holds the screen on Android: 'landscape' and 'portrait' lock to that orientation, 'any' follows the device again. It resolves to `true` when the lock applied and to `false` off Android, so desktop callers need no check. The `OrientationLock` type is exported with it.
- The Controls screen shows Profiles, Bindings and Devices as tabs below 640px wide, and `ControlsGame.listenerFullscreen` lets the listening popover fill the viewport.
- The Controls bindings tabs show one row per action with its bindings in columns (primary, secondary, up to four). Clearing or rebinding a column changes only that binding, and an empty column adds one. `ListenTarget` actions carry an optional `slot`, and `bindProfileSlot` rebinds one mapping of an action.
- Add `ControlsGame.extraDevices`, so a game can list devices of its own in the Controls settings. They show as connected and take the same preset flow as a detected pad.
- Below 640px the Profiles and Devices tabs of the Controls screen show the panel content at full width, with no side panel around it. The panel action (new profile, rescan) is a button at the start of the content. The tab names now come from the `profilesTitle` and `devicesTitle` labels, so the `tabProfiles` and `tabDevices` labels are removed from `ControlsLabels`; `tabBindings` stays.

## Fixes

- Local CI runs lint only the committed change, so the install in the CI worktree no longer forces a whole-tree lint.
- @drizztdourden08/brock-core@0.122.0
- The Capacitor device port keeps one `brock:back` listener and one handler set per page, however often the platform is rebuilt. Back quits the app only when no handler is registered anywhere.
- The web and Capacitor API shim now answers `answer()` with a no-op handler, so a renderer that registers an ask handler boots off Electron.
- The web and Capacitor API shim resolves every base invoke method that returns a list to an empty list, `takeOpenRequests` and the document and widget lists included, so `useAppOpenBridge` no longer throws off Electron. - @drizztdourden08/brock-core@0.122.0
- Local CI runs lint only the committed change, so the install in the CI worktree no longer forces a whole-tree lint. - @drizztdourden08/build-cache@0.122.0
- The Android library build mirrors the SDL3 source into the short CMake folder (on Windows by default), so a second `assembleDebug` no longer fails when SDL's CMake re-checks headers that sit past 260 characters in the pnpm store.
- The Controls binding listener cancels on Escape by `key` or `code`, clears on `key` Delete or Backspace, and ignores a key with an empty `code`. Android WebView sends Escape with an empty code, which used to save an empty keyboard binding.
- The binding clear button is always visible under the `platform-mobile` root class, so the desktop mobile preview shows it too.
- The binding clear button is always visible on devices with no hover or a coarse pointer, such as phones.
- The controls tables scroll sideways when they are wider than their panel, and binding cells keep a readable minimum width instead of clipping on a phone in portrait.

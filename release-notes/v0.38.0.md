# Brock v0.38.0

Brock moves to standards 0.9, so two narrow exceptions are now part of the writing checks instead of something an app has to work around.

## Changes

- A name that must keep its exact spelling, such as a product name or a saved setting key, passes the identifier check once it is listed in the prose allow list (`allow` in `brockEslint` or `options.allow` in `standards.config.mjs`).
- A test may assert the real text its app shows: a string that is the expected value of a matcher on `expect(...)` skips the dash, punctuation and stock phrase checks. Text kept outside the matcher is still checked.

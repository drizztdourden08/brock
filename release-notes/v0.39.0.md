# Brock v0.39.0

Apps can now add their own steps to the managed CI and release workflows, port kit manages saves and ROMs the way a real port needs, and Brock moves to Tessera 0.32.

## New

- App steps in the managed workflows: `workflows.steps` in `brock.config.ts` adds shell or action steps at fixed points of CI (before install, before and after the build, before the tests) and of the release (before install, before and after packaging), with the secrets they read and the platforms they run on. Modules and plugins add steps the same way. `workflows: { ci: 'own' }` hands a workflow file to the app instead.
- In a repo with several apps, the shared CI runs every app's steps, each named after its app and run in its folder, and a setup step that several apps share runs once.
- Port kit saves: rename, overwrite, prune by count or age, and the size of each save; a save's companion files go with it.
- Port kit ROM store: unknown dumps stored and flagged, ROMs read from a zip, several kinds of ROM per app, and a delete that takes the derived files with it.
- Asset work in a worker thread, run as a job with progress and cancel.

## Changes

- Tessera 0.32: Escape and an outside press dismiss anchored parts, a hint follows the pointer, tabs can be disabled with a reason, and the list and detail layout splits by share with a detail side that folds.
- Build options for `define`, a `compilerOptions` override of the managed tsconfig (also for sites), extra resources, an `afterPack` hook, a role and icon per file type, and the Velopack icons.
- Modules: app actions on a controller card, a notice per version in the update dialog, contact email and attachments in a bug report sent through the app, and a probe and run hook for external tools.

## Platforms

- Every Linux job in the managed workflows stays on Ubuntu 24.04.

## Upgrading

- Run `<app> upgrade`, then move any steps you added to a managed workflow by hand into `workflows.steps`, or set the file to `own`.
- An app's own fake of a job handle or the tools API needs the new `setCancellable` and `onChanged` members.

## Fixes

- The release job pushes the version to the workspace's base branch, not GitHub's default branch.
- The electron-vite module shim no longer lands inside a template string, and `brock check` fails when the app package is not an ES module.

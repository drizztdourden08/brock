# Brock v0.40.0

The shell grows the hooks a full app needs: a mobile host, settings that adapt to each user, screens shown per profile or platform, a bug report receipt, and Escape that always closes the right thing.

## New

- A mobile host for Capacitor: files in the app's data folder, a phone layout, the back button, haptics, and remembered window state that survives a restart.
- Screens, pages and cards can show only on some platforms or for some profiles, and a hidden one leaves the menu, search and shortcuts too.
- A hub page can stay mounted while you look at another one.
- The bug report can show a receipt after sending instead of a toast.
- `--screenshot` waits until the app says it is ready, and the capture is always the current frame.
- The renderer writes the session log and records uncaught errors.

## Settings

- A setting can clean its stored value when it loads, change a patch before it is saved, show only when another setting allows it, and offer choices that are disabled with a reason.
- Two new controls: a colour picker and a multiple choice.

## Under the hood

- An app adds its own members to `window.api` by augmenting the IPC namespaces.
- `ui-views.json` is written per key, so an app's own keys are never lost.
- A guard can check every file write, `FileStore.trash` moves files to the trash, and windows can mute their audio.
- Menu entries can turn themselves off, widgets can be disabled, and `brock-electron/node` gives the path and JSON helpers without Electron.

## Fixes

- An app menu named like one of Brock's sections, such as Advanced, joins that section instead of adding a second one, so Escape closes the screen as expected.

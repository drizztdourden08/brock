# Brock v0.43.0

A data file whose text is copied word for word from an outside source, such as a game's dialogue tables or a licence, can now say so, and the writing checks leave that text as it is.

## New

- `@kind verbatim @source <where the text comes from>` in a file's header marks a data file of verbatim text. It keeps the data file rules (no logic, no size limit), and the writing checks skip its string values; its names, comments and header are still checked.
- A verbatim file without `@source` fails lint, and `brock structure` lists every verbatim file with its source, so each exemption stays visible.

## Under the hood

- Standards 0.10, which adds the option the verbatim kind uses.

# Brock v0.44.0

Dev launches no longer get stuck at boot: the first page loads in a fraction of the time, a slow boot finishes instead of failing, and the boot timeouts can be set. Brock also moves to Tessera 0.35.

## Changes

- The dev boot timeout is 120 seconds. An app sets its own with `product.boot.devWatchdogMs` and `product.boot.watchdogMs`, and `BROCK_BOOT_WATCHDOG_MS` overrides both.
- `brock-build/testing` exports `waitForAppPage` and `pageKindOf`, and `launchAppForTest` takes a `userData` folder that it keeps on close, so a test can use its own profile and never grab the splash.
- Tessera 0.35: DensityScope, and parts that replace the last app-side styling of Tessera's parts.

## Fixes

- The splash look is built once per dev server and rebuilt only when its config or files change, so the first page of a dev launch takes milliseconds instead of many seconds.
- A boot that answers after the watchdog fired now recovers: the splash goes back to progress and the app opens. A real failure, such as a page that fails to load, still stops the boot.
- Each finished page load counts as a sign of life, so a slow but working renderer is never declared dead.

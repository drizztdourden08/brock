# Brock v0.45.0

The last round of what a full app needed while moving onto Brock: workers built from the main process, more places for an app's own workflow steps, packaging details, and a mobile host that behaves like a phone app.

## New

- A main-process worker imported with `?modulePath` builds and runs, so port kit's asset jobs can run in the background.
- Port kit can arm its crash watch from the start, write saves raw, and list ROMs by name without hashing; ensure-wasm finds the SDK of the main checkout from a worktree.
- On a phone: the back gesture reaches the app, the title bar can be hidden, the Storage page shows a summary, and a file picker can accept any file with `anyType: true`.
- The update notice gets the release and its files, so an app can warn about a version before it is installed.

## Changes

- Workflow steps can go in the release `prepare` job, and any step can name the jobs it runs in.
- Packaging sets the Windows file details, a copyright and the Linux desktop category from the product, and a description for each file type.
- The `--screenshot` watchdog takes `--screenshot-timeout`, and it exits with code 2 when it fires.

## Fixes

- A plugin listed as an object in `brock.workspace.mjs` loads once.

# Brock v0.45.1

One paragraph for the people who use Brock: what this release changes for them.

## Fixes

- `launchAppForTest` and `assertLaunchable` no longer refuse a built main over a specifier that sits in text. The import check now tokenizes each built file and reads `import`, `export ... from`, `import()` and `require()` from the code only, so a `require('./package.json')` inside a string, template text, a comment or a regular expression (such as a workflow template bundled into main) is ignored. - @drizztdourden08/brock-core@0.45.1 - @drizztdourden08/brock-lint-config@0.45.1 - @drizztdourden08/brock-thread@0.45.1
- The `--screenshot` watchdog now waits at least as long as the boot watchdog: 120 s on a dev launch (or `product.boot.devWatchdogMs`), where a cold start took longer than 20 s and left a black picture, and still 20 s in production unless the production boot watchdog is longer. `screenshotTimeoutMs` of `bootstrapApp` and `--screenshot-timeout` still override it. - @drizztdourden08/brock-core@0.45.1

# Brock v0.45.1

Two fixes for app tests and screenshots.

## Fixes

- The launch check in `launchAppForTest` reads only real code in the built main file, so a `require(...)` that sits inside a string, a template or a comment no longer looks like a missing import.
- In dev, the `--screenshot` timeout follows the dev boot watchdog (120 seconds unless the app sets its own), so a slow first launch still captures the app instead of a black window. Production keeps 20 seconds, or a longer boot watchdog if the app sets one.

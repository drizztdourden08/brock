# Brock v0.46.0

Hubs show one menu only when it helps, pages can follow the app's own state such as being signed in, dev launches start faster, informational windows open small and centred, and the updater finds pre-releases it used to miss.

## New

- A hub with one visible page shows that page alone, without its side menu (`nav: 'auto' | 'always' | false`).
- `<BrockApp showFlags={{ signedIn }}>` lets screens, pages and cards show only in some app states; the menu, hub menu, search and shortcuts update when a flag changes.
- A hub can carry a header backdrop, image, colour or node, and a page can override it.
- A card with `meta.size: 'info'` opens as a small window centred on its content; Credits and About use it.
- `product.profilesRoute` sends the Profiles entry and the first-run profile prompts to a page of the app's own, and a hub bucket can open without a profile.
- Asset jobs can run in a browser worker, so the same extraction works on desktop, Android and the web, and the ROM list reports each asset's size.

## Changes

- Credits, About and Quit are the last group of the menu, in that order.
- Title bar items can export an `order`.
- The browser host recognises a phone, and the file picker can drop its filter on phones only.
- Dev launches pre-bundle Brock, Tessera, React and the app's own dependencies up front, so the first launch no longer restarts halfway, and the browser cache is kept while the dependencies are unchanged.
- Tessera 0.36.

## Fixes

- The updater checks against the full list of versions, so a newer pre-release behind a newer stable fix is offered, and the list reads every release's own history.
- A file dropped outside a drop target no longer sends the window to that file.

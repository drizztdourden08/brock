# Brock v0.47.0

An app's wordmark can replace its name on the splashes and in About, deleting a profile no longer leaves the app stuck, and verbatim text may hold a vendor or assistant name in its strings.

## New

- `product.icons.wordmark` shows the app's wordmark image in place of its name on the boot splash, the failure splash, the installer splash and About, with the name kept as its text alternative.
- `<BrockApp profiles={{ onBeforeRemove }}>` lets an app stop work tied to a profile before it is deleted, or keep the profile.

## Changes

- A title bar action file may export `order` or `meta` beside its default export, as screen and widget files may.
- Standards 0.11: a `@kind verbatim` file also skips the vendor and assistant name check for its string values; its names and comments are still checked.

## Fixes

- Deleting the active profile switches to the most recently used remaining profile and keeps you where you were. Deleting the last one opens the profiles page, and Escape and Home always lead somewhere.
- A ROM whose asset file is empty lists as having no assets.

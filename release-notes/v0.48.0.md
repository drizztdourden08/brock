# Brock v0.48.0

Screens and widgets now load when first used instead of all at once, so a large app starts faster in dev, and Brock moves to Tessera 0.37.

## Changes

- The generated screen, widget, title bar and tour registries load each component on first use; their titles, icons, menu entries, search entries and show rules still load at boot, so the menu and search work at once. The base and home screens load during boot, and a menu row loads its screen when hovered or focused.
- A screen, hub page or widget that is still loading shows one small spinner, and a screen that already loaded opens without one.
- Release builds put each screen and widget in its own chunk.
- Tessera 0.37: the backdrop types are now `Backdrop` and `BackdropFit`.

## Upgrading

- Code at the top level of a screen or widget file now runs when that screen first loads, not at boot. Move anything that must run at startup into a boot task.

# Brock v0.50.0

The View entry of the main menu can now be moved or hidden like any other entry.

## Changes

- The `view` key in the menu configuration takes `group`, `order`, `before` and `after` to move View, and `inMenu: false` or `hidden: true` to take it out of the menu. Other entries can be placed before or after it, and renaming still goes through `windows.view`.
- When View is hidden and a narrow window tucks the pin and full screen buttons away, they appear as `window-pin` and `window-fullscreen` entries in the main menu, which the menu configuration can rename or move too.
- `brock check` warns when View, Pin and Full screen are all out of the menu.
- Tessera 0.37.2.

# Brock v0.51.1

The title bar lists the pin and full screen buttons in the main menu itself when View is hidden, so Brock no longer adds its own copies.

## Changes

- Tessera 0.37.3: with View hidden, a narrow window lists Pin window on top and Fullscreen in the main menu, as plain actions that say what a pick does, with no check mark.
- The menu keys `window-pin` and `window-fullscreen` are still accepted, but they no longer rename or move those rows until Tessera lets each row take its own label and place.

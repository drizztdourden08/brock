# Brock v0.52.1

The review no longer fails the floating widget minimum check when the window is small.

## Fixes

- The `floating-widget-min` review check expects the widget to stop at 240 by 160, or at the main view's size when the main view is smaller, since a floating widget can't be larger than the view it floats in. Its failure message gives the main view's size. The widget sizing itself is unchanged.

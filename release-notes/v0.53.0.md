# Brock v0.53.0

The bug report dialog takes a section of the app's own, a prefilled title, a signed-in identity, several result links and a retry.

## Changes

- `section` in the app's `bugReport` config is a component the dialog shows below the attachments. It gets `setExtras` and `disabled`, and what it sets joins the report's `extras`. `transport` is now optional there, so an app whose transport lives in main can still add a section.
- `bugReport.open({ title })` and `bugReport.setDefaultTitle(title)` prefill the title. Both are cleared when the dialog closes.
- `identity` beside a transport shows "Reporting as" and the identity in place of the contact field, and the report then carries no contact.
- A receipt's `links` each get a button in the receipt view. The single `url` still shows as Open.
- A receipt's `retry` shows Retry upload in the receipt view, even for a transport that uses toasts. A main transport's retry stays in main and runs over the new `bugReport:retry` channel. Main keeps only the latest retry.

# Brock v0.56.0

Brock moves to Tessera 0.39.0 and shows its dates with Tessera's DateText and formatDate.

## Changes

- Tessera 0.39.0. Apps upgrade with `brock migrate`.
- The Profiles screen shows when each profile was last used as a relative time, with the full date on hover.
- The Logs widget and the job dialog stamp each line with a 24 hour clock and seconds in the user's locale, through the new exported `formatLogTime`.
- The updater's version list shows release dates with `formatDate`.
- The hub header search uses Tessera's `grow={false}`. It is 256 pixels wide, narrowing to 160, and the `header-actions__search` class is gone.

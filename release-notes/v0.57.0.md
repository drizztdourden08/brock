# Brock v0.57.0

Brock moves to Tessera 0.40.0, and brock-core drops its old date helpers in favour of Tessera's.

## Changes

- Tessera 0.40.0, which adds `newDisabled` on ItemList and a shared `useUndo` stack. Apps upgrade with `brock migrate`.
- Breaking: brock-core no longer exports `formatDate`, `formatRelativeTime` and `DatePreset`. The `core-date-helpers` migration turns each use into a to-do pointing to Tessera's `formatDate` in `@drizztdourden08/tessera/primitives` and `DateText` in `@drizztdourden08/tessera/composites`.

# Brock v0.59.0

The title bar volume control gets its hover slider, the Widgets menu gets a Developer submenu, a page hides an open kit, and a wide wordmark fits the About card.

## Changes

- Tessera 0.41.0. A `volume` title bar item is now Tessera's volume control: its slider opens on hover or focus and a click mutes. In a narrow window the main menu holds its Mute row and a slider row.
- Breaking: a `volume` title bar item no longer takes `labels`, and `TitleBarVolumeStrings` is gone, since Tessera draws Mute and Unmute. The `volume-item-labels` migration leaves a to-do where they were used.
- Widgets > Developer (key `widgets-developer`) holds every `devOnly` widget and kit while developer tools are on, with each dev kit as its own submenu. `menu: { parent, group, order }` in a widget or kit's meta places it, and a missing parent submenu inside Widgets is created.
- `widgets.force(ids)` opens widgets past their context and dev gates, for command line baselines and end-to-end runs on a fresh profile. A forced kit widget opens its kit.
- `product.icons.wordmark.rendering: 'pixelated'` scales pixel art with hard pixel edges in About and on the splashes.
- In port-kit, `createLiveSettings` applies the last pushed settings each time the core starts running, and gains `dispose()`.

## Fixes

- Opening Home or any page while a kit is open hides the kit's widgets, overlays and bar, and brings them back when the page closes.
- A wide wordmark fits the About card, centred, at most the card's width and 48 pixels high.
- Screenshots wait for lazy screens, widgets and tours to settle and paint, so they never catch a loading spinner. The review's own captures wait too.
- Settings pushed to a port before its core runs are no longer lost.

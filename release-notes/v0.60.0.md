# Brock v0.60.0

Brock moves to Tessera 0.42.0, and a pixel art wordmark scales with hard edges on every splash through Tessera's own option.

## Changes

- Tessera 0.42.0. Apps upgrade with `brock migrate`. Docked panes that leave out `makeRoom` now make room, and an overlay no longer stretches the main view under them.
- The boot failure splash passes `wordmarkPixelated` to Tessera's Splash, and the generated splash page uses Tessera's `ts-wordmark--pixelated` class, when `product.icons.wordmark.rendering` is `pixelated`.
- `brock check` and `brock sync` warn when a smooth wordmark picture is under 48 pixels high, since Tessera now draws it at its own height.

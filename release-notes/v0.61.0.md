# Brock v0.61.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- Three review checks no longer fail on apps that are set up as intended. `<hub>-<page>-row-hint` now points at the first toggle row that has hints, not just the first toggle row, so a bulk row with no hints no longer fails it. For a toggle with `hints.atRest`, whose pointed hint is one of its rest lines and so stays hidden, it passes on the current rest line. A page where no row has hints is now a skipped pass. `bug-report-prefill-cleared` now checks that the next plain open no longer shows the review's title, and expects an empty title only when the app sets no default title, so an app that calls `bugReport.setDefaultTitle` each time the dialog opens passes. `bugReport.hasDefaultTitle()` (the store's new `prefillIsDefault`) says whether the title waiting for the next open came from `setDefaultTitle`. The `buckets` step now evaluates each bucket's `hosts` and `when` rule for the active profile, and reports a hidden bucket as skipped passes of `<hub>-reachable` and `<hub>-pages`, with the reason, instead of failing to open it. It also no longer goes through a hidden bucket to reach another bucket's switch pill.

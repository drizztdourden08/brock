# Brock v0.61.0

Three review checks that failed in real apps now follow what the app shows.

## Changes

- `bugReport.hasDefaultTitle()` says whether the title in the dialog is the default set with `setDefaultTitle`.

## Fixes

- A hub page's row hint check points at the first toggle row that has hints, accepts the hint shown in the row's rest line, and is skipped when no row on the page has hints.
- The bug report prefill check expects the review's title to be gone on the next plain open, and an empty title only when the app sets no default title.
- The buckets step skips a bucket hidden for the active profile, saying why, in place of failing to reach it.

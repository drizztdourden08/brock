# Brock v0.62.0

Escape closes a window and reopens the last one, the full screen title bar draws above widgets, and an app's own setting can drive the developer tools.

## Changes

- Escape on a screen window closes it in one press, from any page or sub-page. Escape with no window open reopens the last one closed, on the same page, tab or sub-page, with its history and scroll offsets, also after a restart. Menus, dialogs, popovers, the palette and text fields still take Escape first. This changes what every app does on Escape. `nav.reopen()` reopens the last window from code.
- Breaking: the navigation store no longer has `escapeTo` and `setEscapeTo`. The `escape-to-removed` migration leaves a to-do at each use.
- `developerTools` on `BrockApp` binds Brock's developer tools to the app's own setting, as `{ get, set, subscribe }` or `developerToolsFromSettings(key)`. Turning it off hides Widgets > Developer and closes every open dev widget, its popped windows and dev kits. Forced widgets stay open.
- The review has a `fullscreen` step: the title bar hides, shows in full above a docked widget at the top edge or with Alt, and comes back after leaving full screen.

## Fixes

- In full screen, the title bar revealed at the top edge draws above docked and floating widgets, not under them.
- A headless review lays full screen out off screen, so it no longer takes over the real screen.

# Brock v0.63.0

A hero can leave out its art, and settings groups with the same id or name merge into one.

## Changes

- `<Art kind="none" />` in a `.hero.tsx` draws no art, not even the brand mascot, like `<Backdrop kind="none" />`. The review checks it as `<bucket>-hero-art-none`.
- A settings tab joins the group named by its new `groupId`, or else the group whose label matches its `group`. The app's own pages come first, then the tabs. brock-display's Display tab carries `groupId: 'app'`. The review fails any hub whose nav shows two groups with the same label (`<bucket>-nav-groups`).

# Brock v0.66.0

Hub windows drop the Back button and share one window across every hub.

## Changes

- A hub window has no Back button. Escape and the hub switch cover going back, and Alt+Left and the mouse Back button still walk the page history. The save status and profile tag sit beside the hub switch at the top, so they take no row.
- Every hub shares one window. Switching hubs keeps its position, size, lock and open state, stored under `brock.hub`. Positions saved per hub by 0.64.0 are not read.

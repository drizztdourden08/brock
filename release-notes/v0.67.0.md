# Brock v0.67.0

Brock moves to Tessera 0.45.0.

## Changes

- Tessera 0.45.0 brings one pane edge everywhere. SidePanel and ListDetailLayout lose `resizable`, ResizeHandle moves to `fold`, and SplitPane's `snapAt` becomes `collapsible`. Brock used none of them. Apps that did follow Tessera's MIGRATION 269 and upgrade with `brock migrate`.

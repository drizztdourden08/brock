# Brock v0.68.0

Brand mascots can now walk along the bottom of an open window and help point to search. Apps using Tessera 0.45.0 receive this through Brock with no extra setup.

## Changes

- A mascot follows open screen windows, idles and wanders along their bottom edge, and stands beside the Ctrl+K search palette with a hint. It respects reduced motion and does not take focus or pointer input. Set `product.mascot` to `false` to disable the walker, or provide `searchHint` to change its hint.
- `BrockApp` accepts `restoreNavigation: false` for apps that should start with no previously open screen. RotP uses this to start with its game view closed.
- The automated review checks the mascot's placement and skips menu screens hidden by a `show` condition.

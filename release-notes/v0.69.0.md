# Brock v0.69.0

Controllers now show up in the Controllers window again, and a headless launch can check a pad without opening a window. Card screens also sit under a single window header.

## Changes

- Add `--input-live`: it turns SDL3 on in a headless automation launch, so a pad can be checked without a window. It stays off by default and refuses, with one warning, while another running instance holds the pad (a lock file in the OS temp folder).
- Draw a card screen under one window header with its content straight in the window body, instead of a second page header and an inner card.

## Fixes

- Fix the Controllers window showing no controllers. The input, catalog, display and secrets modules now keep one instance per app, so the registration step and the window step no longer build two.

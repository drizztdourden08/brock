# Brock v0.70.0

Automation launches no longer put a window on the desktop, and they still draw WebGL. An app can also declare a window with a side nav in a few lines.

## Changes

- Hide every window of a headless launch. Any automation flag without `--visible` (review, screenshot, e2e, `--no-focus`) now creates its windows hidden and draws them offscreen. No window, taskbar flash or focus steal reaches the desktop. `--visible` is the only way to show one.
- Render a hidden launch on the CPU. Hardware acceleration is off, so a machine without a GPU no longer crashes the GPU process. WebGL still draws, on SwiftShader, the CPU renderer Chromium ships, and gives the same pixels on every host. A screenshot baseline run uses the same path.
- Add `--gpu`. It keeps hardware acceleration in a hidden launch, for a heavy WebGL check on a machine that has a GPU. A host without a GPU must not pass it.
- Add `defineWindow`, a declarative window with a side nav and one pane per nav item. Items take a label, an icon, an id, a disabled flag and a badge, with their content in a `.card.tsx` or `.layer.tsx` file. The active item follows the `nav` route param, and the nav folds to a bar in a narrow window.
- Add the `fill` header mode. A card with `fill: true` in its meta draws the one window header and a body with no padding or scroll wrapper.
- Require Tessera 0.48.0, which draws the nav item badge.

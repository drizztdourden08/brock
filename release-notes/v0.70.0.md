# Brock v0.70.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- A headless launch (any automation flag without `--visible`) is now hidden: its windows are never shown, so no window, taskbar flash or focus steal reaches the desktop; `--visible` is the only way to show one. A hidden launch also turns hardware acceleration off, so its offscreen windows draw on the CPU and a machine without a GPU no longer crashes the GPU process.
- A hidden launch now draws WebGL. Hardware acceleration stays off, and the launch adds `enable-unsafe-swiftshader`, so a WebGL canvas renders on SwiftShader, the CPU renderer Chromium ships. It draws the same pixels on every host, with or without a GPU. A screenshot baseline run uses the same path. `--gpu` keeps hardware acceleration in a hidden launch, for a heavy WebGL check on a machine that has a GPU. A GPU-less host must not pass it.
- Add `defineWindow`, a declarative window with a side nav and one pane per nav item: nav groups and items (label, icon, id, disabled, badge) with their content in a `.card.tsx` or `.layer.tsx` file, the active item from the `nav` route param, and the nav folding to a bar in a narrow window. A card with `fill: true` in its meta now draws the one window header and a body with no padding or scroll wrapper. The Tessera minimum is now 0.48.0, which draws the nav item badge.

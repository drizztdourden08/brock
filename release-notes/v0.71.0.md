# Brock v0.71.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- Add `bare: true` to a card's meta. A bare card looks exactly like the Home hub window: no title row, the hub padding, the corner close and lock, no screen switcher, movable, and the shared hub window storage key. `brock-react` now exports that key as `HUB_WINDOW_KEY`.

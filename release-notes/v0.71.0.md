# Brock v0.71.0

A card screen can now look exactly like the Home hub window.

## Changes

- Add `bare: true` to a card's meta. A bare card has no title row, the hub padding, the corner close and lock, and no screen switcher. It moves like a hub and shares the hub window storage key.
- Export the hub window storage key from `brock-react` as `HUB_WINDOW_KEY`.

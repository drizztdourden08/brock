# Brock v0.71.1

Listing controllers no longer rescans the hardware, so polling the list cannot drop a pad.

## Changes

- Add `input:refresh` (`refresh()` in the input API). It runs a full controller scan on demand. Call it from a user action, never on a timer.

## Fixes

- Fix `input:list` running a full controller scan on every call. It now returns the cached list. An app that polled it every few seconds could drop an Xbox pad and list it twice after a replug.

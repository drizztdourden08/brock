# Brock v0.72.0

An app can now draw a controller's controls in their real places, and a Bluetooth Xbox pad lists once on Windows.

## Changes

- Report each controller's state by physical place. `onPadState` and `usePadState` give a `PadState` keyed by slot, such as `face.south`, `stick.left` and `trigger.right`. Stick Y is up positive, and triggers run from 0 to 1. The slot names match Tessera's `ControllerSlotId`.
- Add a `family` hint to each ready `DeviceEntry`: `xbox`, `playstation`, `nintendo` or `generic`, from SDL's gamepad type. An app uses it to pick a controller layout.
- Move the SDL3 addon to 1.2.0.

## Fixes

- Fix a Bluetooth Xbox pad listing twice on Windows. SDL opens it through XInput as `045e:02ff`, and the HID listing also showed it as `045e:0b13`, an unavailable second pad. The addon now marks HID devices that share a Windows device container with an XInput interface, so each open pad claims its own listing. Two real pads still list as two.

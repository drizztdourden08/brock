# Brock v0.73.0

A bare card now names itself in a small corner chip.

## Changes

- Show a bare card's title and icon in the corner chip that Tessera 0.49 draws on a window with no title row. A hub keeps the chip off, because its floating switch already names it. A bare card that also draws its own title in the body now shows it twice, so drop the one in the body.
- Require Tessera 0.49.0.

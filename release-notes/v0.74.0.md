# Brock v0.74.0

Controller state now plugs straight into Tessera's ControllerLayout.

## Changes

- Change `PadState` to `{ slots, extras }`. `slots` is keyed by Tessera's `ControllerSlotId`, the 20 silhouette controls, with pressed, value, x and y. `extras` lists the controls the silhouette does not place, each with an id, a label and its pressed state: the spare buttons, the four paddles and the touchpad. Pass both to Tessera's `ControllerLayout`. Code that read `pad['face.south']` now reads `pad.slots['face.south']`.
- Re-export `ControllerSlotId` and `ControllerSlotState` from Tessera. Brock's own `CONTROLLER_SLOT_IDS` is gone: import it from `@drizztdourden08/tessera`.
- Require Tessera 0.50.0.

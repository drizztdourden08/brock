# Brock v0.74.1

A controller layout now shows only the extra controls the pad has.

## Fixes

- Fix `PadState.extras` listing every extra control for every pad. It now lists only the controls the pad reports, so an Xbox pad without paddles shows no paddle rows. Labels follow the pad family: P1 to P4 on an Xbox Elite, RB, LB and the Fn buttons on a DualSense Edge, GR and GL on Nintendo pads. Ids are unchanged. When a pad reports no capabilities, every extra is listed, as before.

# Brock v0.75.0

Brock now runs on Tessera 0.52, which drops light backgrounds.

## Changes

- Breaking: require Tessera 0.52.0. `product.icons.rim` takes `'light'` only, and `brock icons` no longer reads `brand/dark-rim`. The hero brand art and the About screen follow the new Tessera types. Remove `rim: 'dark'` and any `ground` prop on `BrandMark` or `Logo`. The `light-ground-removed` migration lists each one as a to-do when you run `brock upgrade`.

# Brock v0.76.0

Brock now carries what a document editor needs: files at user paths, a document title, remappable commands, and a way for main to ask a window a question.

## Changes

- Breaking: a command keymap replaces the shortcut helpers. Every shortcut is now a command in one registry: `{ id, label, icon?, group?, chord?, scope?, whileTyping?, when?, run }`. A chord is `'Mod+S'`, a list, or `{ mac, other }`. `Mod` means Ctrl on Windows and Linux and Cmd on macOS, and only that key, so Win+K no longer opens Search. Declare commands with `<BrockApp commands>`, `RendererModule.commands`, `useCommands(defs)` in a screen, or `commands.register(defs)`. Run one with `commands.run(id)`. A plain key does nothing while the user types in a field, and a Mod chord still fires. A command scoped to the open screen wins over a global one. Users remap chords on `KeymapPage`, which an app adds as a settings page file. Remaps are stored per profile under `keymap`. Menus, title bar tooltips and the Ctrl+/ dialog show the current chord. Brock's own shortcuts keep their defaults. `matchesShortcut`, `parseShortcut` and `ParsedShortcut` are removed: use `commands.matches(id, event)` and `formatChord`. The `shortcut-helpers-removed` migration turns each use into a to-do.
- Add document files at user paths. On Electron, `usePlatform().documents` gives `open`, `saveAs`, `read`, `readText`, `write` and `writeText`. Open and Save As return the absolute path, or null on cancel. A write is atomic: Brock writes a temp file beside the target, flushes it, then renames it over the target. The renderer may touch only a path the user picked in a dialog this session, or one main code allows with `ctx.documents.allow(path)`.
- Add a document title. `useDocumentTitle({ name, dirty })` shows the open document in the title bar and the OS window title, as `name * - App` while it has unsaved changes.
- Add `product.singleProfile: true`. The app runs with one implicit Default profile, made silently on the first launch, with no profiles screen and no Profiles menu entry.
- Let main ask a renderer window a question. Declare the channel with `ask<(id: string) => Promise<Snapshot>>()('doc:snapshot')` in `defineChannels`. The renderer answers with `answer(channel, handler)`, and main calls `await ctx.ask(win, channel, ...args)`. Each ask times out after 10 seconds (`ctx.askWithin` sets another limit). It rejects with a clear message when the window has no handler, when the window closes, or when the handler throws.

## Fixes

- Fix lint failing on the files a config generator puts in an upgrade worktree. `brock prose` skips an untracked `.ai-config.json` and `.mcp.json`. The markdown lint skips a `CLAUDE.md`, `AGENTS.md` or `.github/copilot-instructions.md` that says it is generated. A guide an app wrote itself stays linted.
- Fix `pnpm lint:md` failing in a workspace app. `brock sync` now writes the markdown lint config into each app that has a `lint:md` script.
- Fix a workspace scaffold keeping the template's `brock.workspace.mjs` and root-only dependencies in the app. Only the workspace root owns them now. The Tessera range in the workspace catalog now follows brock-react, so it does not go stale.
- Fix `brock knip` failing on a fresh workspace. `brock adopt` now writes a root workspace in the knip config.

# Brock v0.77.0

Hubs can hold pages that come and go at runtime, document apps get recent files, recovery and a menu bar, and the input module lists every controller SDL knows.

## Changes

- Add live hub pages. A `<id>.live.tsx` file in a hub bucket or group folder is a nav slot that fills at runtime. It default-exports a hook that returns `LivePage[]` (`key`, `title`, `icon`, `badge` of `'ok'` or `'warn'`, `render`), and exports `meta: LiveMeta` (`icon`, `empty`, `title`, `order`, `keywords`, `devOnly`). The slot sorts by `meta.order` among the static pages. The badge shows as a status dot, `empty` shows as a disabled entry while the list is empty, and `keywords` feed the hub search. An entry opens at `<bucket>/<id>/<key>`. When it disappears, the hub shows the first static page of the group. See Live hub pages in `docs/app-structure.md`.
- Add recent documents. The documents port gains `recent()`, `clearRecent()` and `openRecent(path)`: a short list per profile, filled on Open and on save. Missing files drop out, each entry goes to the OS jump list or Dock menu, and a recent file reopens only through the document allowlist. brock-react adds `useRecentDocuments` and `useRecentMenu`.
- Add recovery snapshots, off until an app uses them. `snapshot(key, data)`, `recoverable()`, `restoreSnapshot(key)` and `discardSnapshot(key)` store a copy of unsaved work in the profile folder, cleared on a clean save. brock-react adds `useRecoverable` and an optional `RecoveryPrompt`.
- Add an opt-in menu bar row. Pass `<BrockApp menuBar>` a list of `{ id, label, entries }` menus whose entries are command ids, `'separator'` or submenus. Labels, icons and chords come from the command registry, and an entry is greyed out while the command's `when()` is false. Alt opens the first menu, the arrow keys move, and Escape closes. The hamburger stays.
- Add `disabled` to title bar buttons. A button with a `command` is disabled while that command's `when` is false, so Undo and Redo follow the document. A disabled button ignores clicks. It is not dimmed yet: that look waits on Tessera.
- Add `input.mapping.list()`. It returns every gamepad mapping SDL knows as `{ guid, name, vid, pid, platform?, family? }`, so an app can show a searchable directory of supported controllers. The SDL3 addon moves to 1.3.0. With an older addon, with controllers off, or on Android, it returns an empty list.

## Fixes

- Fix knip reporting Tessera usage files as unused. The knip config that `brock adopt` writes, and the app template, now list `src/views/*/*.usage.ts` as entries.

# Brock v0.79.0

A document app can now ask Save, Discard or Cancel before it quits, and keep exports off the recent list.

## Changes

- Add an async quit guard. `onBeforeQuit` on `BrockApp` and on a module returns `'quit'` or `'stay'`, sync or async. The first `'stay'` keeps the app open, and a guard that throws counts as `'stay'`, so a failed save never closes the app. `saveBeforeQuit({ dirty, save })` builds the usual guard with a Save, Discard and Cancel dialog. A second close while the dialog is open does not stack another dialog.
- Hold native closes for apps with a guard. Once an app registers a guard, Alt+F4, the taskbar, the OS and `app.quit()` run the same checks as Quit. An app with no guard closes at once, as before. A window that does not answer within 5 seconds is treated as hung and closes. `window.close()` from app code goes through the guard too, and `window.close({ force: true })` closes at once.
- Let a write skip the recent list. `documents.write` and `documents.writeText` take `{ recent: false }` for an export such as a PNG. The file then stays off the recent list and the OS recent menu.

# Brock v0.80.0

An app can now start with no window and keep a tray icon, ask questions at start-up, and talk to its helpers over bridge v2. This release has three breaking changes, each with a migration.

## Upgrading

- Move the helper bridge to protocol 2. A helper built against 0.78 or 0.79 cannot talk to an app on this version. Rebuild it with `brock build` and ship it with the app. `bridge.emitTo` now returns a count. Migration `bridge-protocol-2` leaves a to-do at each `connectBridge` use and each `.emitTo(` call.
- Turn the big page header off on hub pages by default. A page shows it again with `showHeader: true` in its meta. A page with `header: { primary, search }` keeps it, a page with tabs keeps its tab bar, and a sub page keeps its back button. A page that fills the header with `PageActions` needs `showHeader: true`. Migration `hub-page-header-off` lists each page with no header setting.
- Make `ctx.window` a function with a `show()` method, and add `isBackgroundLaunch()` to `AutomationFlags`. A hand-built `MainContext` or flags object in a test needs the new members. Migration `main-context-window-show` leaves a to-do at each one.

## Changes

- Add bridge v2. `ctx.bridge.open()` and `ctx.bridge.close()` open and close the bridge at run time, each open with a new secret. `bridge.openOnBoot: false` keeps it closed until the app opens it. Handlers get `call.connectionId`, and `bridge.onOpen`, `bridge.onClose` and `bridge.connections()` follow clients. `bridge.emit` and `bridge.emitTo` push events, which a helper hears with `client.on`. Every server message is signed with the session key. A connection holds at most 4 MiB of unread output. `BridgeError` takes `{ code, data }`, which reach the client as fields.
- Add background launch. A `--background` launch, or a `beforeWindow(ctx)` hook that returns `'skip'`, starts the app with no splash and no window, while the boot and the bridge still run. `ctx.window.show()` creates the window on demand. In background mode the app keeps running when its last window closes.
- Add an opt-in tray icon. `product.tray` or `ctx.tray.set({ tooltip, icon, menu })` adds it. A left click shows the window, and the menu takes show and quit actions, id items for `ctx.tray.onItem` and separators.
- Add start-up prompts. A prompt is `src/startup/<id>.prompt.ts`, default-exporting `defineStartupPrompt({ order, run(ctx) })`. Brock runs them once per launch, one at a time, after the window shows, a profile is active and any first-run tour has ended. They never run on an automation launch. The `startup-prompts` migration wires them into `src/main.tsx`.
- Let `confirmChoice` draw a select. `look: 'select'` uses Tessera's `Select`, with `searchable`. Every confirm dialog also takes `facts: { label, value }[]`, drawn under the message.
- Add bare hub pages. `bare: true` in a page's meta renders it straight into the content slot with no card, padding, header or scroll area. `pages: 'bare'` on a bucket makes every page of the hub bare.
- Flip Electron fuses in packaged apps. `NODE_OPTIONS` and `--inspect` no longer work on a packaged app. The app loads only from its asar, cookies are encrypted, and asar integrity is checked on Windows and macOS. `RunAsNode` stays on only when the app declares helpers. The cookie fuse is a one-way change for existing cookie stores.
- Unpack libusb with 7-Zip in the Windows addon build, and skip the download when the pinned version is already there.

# Brock v0.82.0

Commands can now belong to a part of the window, the controller parts move into the input module, and a headless Node server gets data domains, secrets and a runtime of its own.

## Upgrading

- Run `brock migrate --run documents-access-async` if the app upgraded from 0.80 to 0.81.0. Brock 0.81.0 filed that migration under 0.80.0, so the upgrade skipped it. It is now filed under 0.81.0, and `brock migrate --run <id>` runs one migration by id at any version.
- Import ControllerLayout, StickPlot and PressedGrid from `@drizztdourden08/brock-input/renderer`. The `controller-components-to-input` migration rewrites the imports from Tessera. Their CSS blocks gain an `input-` prefix, and their strings ship with the component, so a Tessera strings override no longer reaches them.

## New

- Add focus zones for commands. A command with `zone` fires only while focus sits inside an element marked with `{...commandZone('canvas')}`, and it ranks above a scoped and an unscoped command with the same chord. The same chord in different zones is not a conflict. A command bound to Mod+C, X, V, A or Z wins over the native Edit menu on every platform.
- Draw a compact hub page header with `showHeader: 'compact'`. It keeps `PageActions`.
- Report where each controller mapping came from. `input.mapping.list()` entries carry `source` (`builtin`, `bundled` or `user`), the `mapping` line and `inputCount`.
- Run a server with no window. `runServer(start)` from `@drizztdourden08/brock-electron/server` resolves the data folder, logs to stdout, stops on SIGTERM and SIGINT, and writes a heartbeat that `main.mjs health` checks. `embedServer(start, ctx)` runs the same server inside the desktop app.
- Use data domains under plain Node. `createDataDomains(dataDir, defs)` from `@drizztdourden08/brock-electron/node` gives the same atomic writes and path guards as `ctx.storage`.
- Keep secrets in a headless app. `createNodeSecretStore({ dataDir })` from `@drizztdourden08/brock-secrets/node` stores them in a 0600 file, and `BROCK_SECRET_<KEY>` overrides a key. This store is not encrypted at rest.
- Give a release step GitHub permissions. A step under `workflows.steps.release.*` takes `permissions`, and sync lifts them onto its job.
- Attest release files. `workflows.attest: { paths, stage }` adds build provenance to the Linux release job and writes a Sigstore bundle beside each file.

## Under the hood

- Let a `.live.tsx` file under `src/screens` declare its hook. The lint config no longer asks for a re-export from a view.

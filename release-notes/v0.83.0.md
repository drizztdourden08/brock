# Brock v0.83.0

An app can now build a server with no window, publish its own library packages, attest each release file on its own, and put a neutral third button in a confirm dialog.

## Upgrading

- Move to Tessera 0.53. `brock-react` now requires `^0.53.0`.
- Name a package listed in `workflows.publish` as `@<owner>/<app>-<subject>`. `brock structure` asks for that form, and every other workspace package keeps `@<app>/<subject>`.
- Expect `brock sync` to rewrite the icon ignore lines. They now sit in a marked block that names only the apps with `icons.brand`, and `brock adopt` no longer writes them.

## New

- Build a server with no window. `targets: ['server']` makes a windowless app, and `['desktop', 'server']` ships both. `brock server build` bundles `server/main.ts` into `dist/server/main.mjs`, and `brock server dev` rebuilds and restarts it on change. The bundle refuses Electron and native addons with a clear error.
- Publish workspace libraries. `workflows.publish: { packages }` adds a `publish-packages` job to the managed release workflow, which builds each package and publishes it to GitHub Packages, skipping a version that is already there.
- Attest each release file on its own. `workflows.attest` takes `perFile: true`, which gives each matched file a bundle with one subject. `BrockWorkflowOptions` now types `attest` and `publish`.
- Add a third button to a confirm dialog. `confirmAction` and `confirmChoice` take `alternate: { label, onSelect, tone, closes }`. It is neutral by default and keeps the dialog open unless `closes` is set.
- Give a disabled title bar item a reason. `disabledReason` shows as its tooltip, and a status item takes `disabled` too.
- Leave a setting row without a hint. `SettingItem.hint` is optional.

## Changes

- Keep every confirm dialog button on one row: the alternate on the left, Cancel and the confirm button on the right.

## Fixes

- Stop failing the review on the browser notice `ResizeObserver loop completed with undelivered notifications.`. Every other console error still fails it, and `gate-context-only-reopens` now says which way the window was wrong.
- Stop ignoring the icon files of an app without `icons.brand`, which supplies them itself.

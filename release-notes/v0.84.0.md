# Brock v0.84.0

A server app can now be packaged for Linux, an app can add entries to the View menu, and sync tells you when it moves a dependency range.

## Upgrading

- Move to Tessera 0.54. `brock-react` now requires `^0.54.0`. Tessera 0.54 removes its controller composites, which Brock has shipped in `brock-input` since 0.82.

## New

- Package a server app. `brock server package` builds a Linux tarball with a pinned, checksum-checked Node binary, a Docker build context, and with `--deb` a .deb with a sandboxed systemd unit. `server.node`, `server.osPackages`, `server.ports`, `server.image` and `server.arch` configure it.
- Add entries to the title bar View menu. The children of an app menu item keyed `view` appear after Tessera's own View rows, and the palette lists them.

## Changes

- Name each dependency range `brock sync` moves back to the `brock.version` pin, with the command that moves the pin. `brock migrate` warns when `--report` lands outside the root.

## Under the hood

- Refuse a server `product.id` that names a system account or a privileged group, and refuse an existing account the package did not make.

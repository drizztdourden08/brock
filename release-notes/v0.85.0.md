# Brock v0.85.0

A server app now builds, checks and ships from the managed workflows, and Brock moves to Tessera 0.55.

## Upgrading

- Move to Tessera 0.55. `brock-react` now requires `^0.55.0`. Tessera 0.55 adds ContextMenu, VirtualList, a marquee and AnchorPicker, and needs no code change in Brock.

## New

- Check a server app in CI. A `server` job builds the bundle, starts it on a temporary data folder and waits for its health check.
- Ship a server app from the release workflow. `build-server` packages the tarballs and the .deb for each `server.arch` and attaches them to the release. `publish-server-image` pushes the Docker image to `server.image` on ghcr.io, tagged with the version, and `latest` when the release is set as latest. It is the only job that can write packages.

## Under the hood

- Pin the Docker actions the server jobs use to full commit SHAs. A desktop-only app's workflows are unchanged.

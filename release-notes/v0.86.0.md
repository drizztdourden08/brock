# Brock v0.86.0

The server app kind is complete: a new app can start as a server, and any repo can now get the launch command.

## New

- Scaffold a server app. `create-brock --platforms server` writes a windowless app with `server/main.ts`, `server/start.ts` and `server/data-domains.ts`. `--platforms desktop,server` also embeds the same server in the desktop app through a boot task. `brock platform add server` adds the starter to an existing app.
- Give any repo the launch command. `brock-thread link` installs the repo command for a repo with a `brock.workspace.mjs`, and a repo that already owns a command forwards to `runThreadCli(argv)` from `@drizztdourden08/brock-thread/cli`.
- Show shortcut hints. `chordKeys(chord, mac)` turns a chord into its keycaps, and `isMac()` and `useIsMac()` read the platform.

## Changes

- Document the server kind in `docs/architecture.md`: runtime, build, packaging, workflows and the security notes.

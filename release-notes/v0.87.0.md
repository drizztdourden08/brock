# Brock v0.87.0

Apps can now dock toolbars, helpers can reach the app more fully, and server apps can carry optional native addons.

## Upgrading

- Move to Tessera 0.56. `brock-react` now requires `^0.56.0`, and the lockfile takes 0.56.1. Migration `toolbar-files` wires `src/toolbars` into `src/main.tsx`.

## New

- Dock toolbars. `defineToolbar({ id, label, defaultSide, render })` in `src/toolbars/<id>.toolbar.tsx` adds a toolbar to Tessera's ToolbarDock around the widget area. Each profile keeps its own toolbar layout, and `useToolbarMenuEntries()` gives a Toolbars menu with its own Reset toolbars.
- Relay an ask channel to helpers. `relayAsk(bridge, ASK, { window, validate })` lets a helper call one renderer ask channel through the bridge, with at most 8 requests in flight.
- Start the app from a helper. `appLaunch()` describes how to start the app, main writes it beside the bridge discovery file, and helpers use `readAppLaunch` and `startApp`.
- Confirm from main. `ctx.dialogs.confirm({ title, message })` shows a native dialog, even while the window is hidden.
- Publish workspace libraries on their own. With `workflows.publish` set, sync also writes `publish-packages.yml`, started by hand, with an optional `packages` input.
- Carry optional native addons. `server.optionalAddons` names packages whose guarded addon load becomes a stub, so their own fallback runs and no binary ships. `resolveDataDir` is exported from `/server`.
- Prepare the Linux test job. `workflows.testEnv` installs `linuxPackages` and, with `userNamespaces`, lets the tests create user namespaces, as a bubblewrap sandbox needs.

## Changes

- Bring a window kept off screen by an automation launch onto the screen when code calls `ctx.window.show()`. The window is opened again on screen, so its page reloads.
- Let `--background` work for a named instance.

# Brock v0.87.1

Two fixes for apps on 0.87.0.

## Fixes

- Type `server.optionalAddons` in `BrockServerOptions`, so a `brock.config.ts` that sets it typechecks. The build already read it in 0.87.0.
- Accept any standards 0.x in brock-build, create-brock, brock-lint-config and brock-thread, so a repo on standards 0.12 keeps one copy and `standards sync` no longer fails with "Cannot redefine plugin".

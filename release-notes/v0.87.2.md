# Brock v0.87.2

A fix for server and helper bundles that carry CommonJS packages.

## Fixes

- Give server and helper bundles `__dirname`, `__filename`, `require.resolve`, `require.main` and `require.cache` for inlined CommonJS code, so a package such as ssh2 that reads `__dirname` at load no longer stops the server at start. They point at the bundle folder, not at the original package folder.

# Brock v0.88.0

An app can now manage the files inside a granted folder, and a server stays up until it is told to stop.

## New

- Manage files in a granted folder. `documents.trash(path)` moves a file or folder to the OS trash, `documents.rename(from, to)` renames inside one grant, `documents.mkdir(path)` makes a folder, and `documents.revokeFolder(path)` gives a grant back from the renderer. Every one runs the same checks as a write, on the real path.
- Watch a granted folder. `documents.watch(folder, options, listener)` reports added, changed and removed files, and stops on unsubscribe, revoke, page reload and window close.
- Restore a folder without the picker. Folders the user picked are remembered per profile, signed with the install's key, and `documents.regrant(path)` restores one that still passes today's checks. `rememberedFolders()` lists them, with `available: false` for one that is missing, and `forgetFolder(path)` removes one.

## Changes

- Refuse a rename that would put a file into a protected place it was not in before, such as a folder renamed to `.github` or `WindowsPowerShell`. A project folder that already holds `.git` or `.vscode` can still be renamed.

## Fixes

- Keep a server process alive until SIGTERM, SIGINT or `stop()`. A server that opens nothing, such as the starter, no longer exits right after it starts.
- Stop refusing a legitimate write when a folder appears between two checks of a burst of writes.

# Brock v0.88.1

Two fixes for apps that run headless or start from a helper.

## Fixes

- Let `ctx.dialogs.confirm` show on a plain `--no-focus` launch when it is asked with `showOnAutomation: true`. A review or screenshot launch still never shows it, and the default stays false.
- Start the app folder from `appLaunch()` in dev. It walks up from the app path to the package.json whose `main` is the running entry, so an app started as `electron dist/electron/main.js` can be started again from a helper.

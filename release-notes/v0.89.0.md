# Brock v0.89.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- `brock-react` now requires Tessera `^0.57.0`. The release adds 48 pixel icons, Toolbar items that take any node as `icon`, and a public `useHoverOpen`. It has no MIGRATION entry, and Brock needed no code change for it.

## Fixes

- Run `brock knip` from an app folder against the workspace config. A run from `apps/desktop` read only the app folder, so it had no test entries: it flagged test-only exports and unused files that the run from the repo root accepts. When the repo above lists the folder under `workspaces` in its `knip.json`, the command now runs knip from that repo with `--workspace` set to the folder, so the app run and the root run give the same answer. A run that passes its own `--workspace` is left alone. - @drizztdourden08/brock-core@0.89.0 - @drizztdourden08/brock-lint-config@0.89.0 - @drizztdourden08/brock-thread@0.89.0
- `appLaunch()` finds the entry file as the first argument that is not a flag, so an app started by Playwright or launchAppForTest with `--inspect=0` in front still records its app folder and can be started again from a helper. - @drizztdourden08/brock-core@0.89.0

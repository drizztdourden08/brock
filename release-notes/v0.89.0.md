# Brock v0.89.0

Brock moves to Tessera 0.57, and two tooling fixes land for workspace repos and helper launches.

## Upgrading

- Move to Tessera 0.57. `brock-react` now requires `^0.57.0`. Tessera 0.57 adds pixel icons, toolbar items that take any node as their icon, and `useHoverOpen`, and needs no code change in Brock.

## Fixes

- Run `brock knip` from an app folder inside a workspace against the workspace config, scoped to that app, so it no longer flags test-only exports and test files.
- Find the app folder in `appLaunch()` past leading flags such as `--inspect=0`, so an app started by Playwright or launchAppForTest can be started again from a helper.

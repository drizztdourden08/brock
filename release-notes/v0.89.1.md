# Brock v0.89.1

App commands now work from any folder of the repo, and a build never reinstalls the repo on its own.

## Fixes

- Find the app from any folder. `dev`, `build`, `package`, `icons`, `start`, `add`, `platform`, `web` and `server` use `--app <dir>` when given, else the nearest folder with brock.config.ts above the current one, else the workspace's only app. A workspace with several apps lists them and asks for `--app`.
- Never reinstall the repo from a build. When the Electron binary is missing, Brock re-runs only Electron's own install step. If the binary is still missing, it prints `pnpm install` for the repo root and stops.

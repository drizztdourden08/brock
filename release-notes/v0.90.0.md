# Brock v0.90.0

A settings page can now read and write a value source the app provides, and file associations can take their icons from the brand.

## New

- Bind a settings page to an app value source. A page, a tab or a section names `source: { get, set, subscribe }`, and its rows read and write through it instead of profile settings. Search, the build-time seeds and the palette still find the rows. Profile settings stay the default, and source rows have no reset.
- Take file type icons from the brand. When the brand ships `filetypes/<type>/` with an .ico, an .icns and PNGs, `brock icons` copies them into `build/filetypes`, and each file association gets its icon unless the app set one. Nothing changes for a brand without that folder.

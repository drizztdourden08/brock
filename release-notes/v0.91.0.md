# Brock v0.91.0

Opening or saving a file can now also grant the folder around it, after the user says yes.

## New

- Grant the containing folder on open and save. `documents.open` and `documents.saveAs` take `grantFolder: 'ask'`, or `{ ask: true, levels }` to go up to two levels, so a palette in `../palettes` is covered. After the pick, a native dialog names the folder and asks to allow it. A yes grants it through the same checks as a picked folder and remembers it for the profile. A no, a refused folder or an automation launch keeps only the file. The answer is then `{ path, folderGranted, folder, reason }`.

# Brock v0.92.0

Brock moves to Tessera 0.58, and file type icons now come from the brand Tessera ships.

## Upgrading

- Move to Tessera 0.58. `brock-react` now requires `^0.58.0`. Tessera 0.58 adds Bxel's file type icons, toolbar click menus, VirtualGrid and DynamicInput validation, and needs no code change in Brock.

## Fixes

- Take file type icons from the plain brand folder when a light-rim brand has none of its own, since Tessera ships `filetypes/` only there. `brock icons` now copies them for both.

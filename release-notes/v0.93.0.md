# Brock v0.93.0

An app can now show a file in the file manager, and its own shortcuts win over Brock's built-in ones.

## New

- Show a file in the file manager. `documents.reveal(path)` in the renderer and `ctx.documents.reveal(path)` in main open the OS file manager on a file the app can already read, after the same check as a read. They answer `{ revealed, reason }` and never throw.

## Changes

- Let an app's command take a chord from a built-in one. A built-in command drops a default chord when an app, route or runtime command uses the same chord, so an app's Alt+Enter wins. Toggle fullscreen keeps F11. A chord the user set on a built-in command never yields.

# Brock v0.93.1

Generated files stop changing on their own, and the key routing rules are written down.

## Under the hood

- Document who gets a key in `docs/architecture.md`: commands run on keydown and win over the Edit menu, `whileTyping` and zones keep text fields working, a menu click fires the DOM copy events, zones rank before scope, and built-in chords yield to app commands.

## Fixes

- Write every generated `.brock` file with LF line endings, and compare without regard to line endings before writing, so a build no longer rewrites an unchanged file. A `tessera guide` file whose only change is its line endings is put back.

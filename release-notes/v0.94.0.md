# Brock v0.94.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- Tests can now exercise the folder grant of `documents.open` and `documents.saveAs`. `grantFolder: { ask: true, showOnAutomation: true }` shows the native folder question on a plain `--no-focus` launch, like `ctx.dialogs.confirm({ showOnAutomation })`, and it stays refused on `--review` and `--screenshot` launches. For hidden tests that cannot click a dialog, the launch flag `--answer-folder-grants=grant|decline` answers the question without showing it. It is honoured only on a headless automation launch of an unpackaged app, and ignored anywhere else, with one log line when the app first asks for a folder. It grants the same folder a human yes would, without remembering it, and only when the app asked with a valid `grantFolder` option. No change is needed in an existing app.
- `BucketDef` takes `switcher: false` (default true) to keep a bucket out of the top hub switcher. `menu: 'hidden'` only drops the app menu entry, so such a bucket still showed as a tab. A switcher-hidden bucket still opens through its menu entry, its shortcut, a search result and `open('bucket/page')`, and the switcher shows no tab as selected while it is open. `defineHub` takes the same `switcher` field.
- Brock is now built and tested on Tessera `^0.59.0` (the workspace catalog). `brock-react` now takes any Tessera from `>=0.58.0 <1` as its peer, so a consumer can move to a newer Tessera minor without waiting for a Brock release. Brock is tested on the catalog version only. The release adds VirtualGrid sections, a scroll ref and marquee select, and a `.bxel` file icon. It has no MIGRATION entry, and Brock needed no code change for it.

## Fixes

- Catalog ranges that YAML cannot read plain are now quoted. `brock upgrade` wrote `>=0.58.0 <1` as the Tessera catalog value, and pnpm then failed on the app's `pnpm-workspace.yaml` with a line break error. The upgrade, `mergeCatalog` and the scaffolder now share one helper, `yamlScalar`, that quotes a value only when it needs it (`^1.2.3` stays plain). The catalog readers strip the quotes, so a quoted value round-trips. Upgrading from a Brock checkout now sets the Tessera catalog to the version that checkout is tested on, not to the wider peer range.
- Brock is now built and tested on Tessera `^0.60.0` (the workspace catalog). The `brock-react` peer range is unchanged at `>=0.58.0 <1`. The release adds a `fit` prop to Grid and moves the ControllerSilhouette anchors to match real pads. It has no MIGRATION entry, and Brock needed no code change for it.

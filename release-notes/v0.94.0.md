# Brock v0.94.0

Brock now builds on Tessera 0.60 and accepts any Tessera 0.x from 0.58, tests can answer the folder grant question, and a bucket can stay out of the hub switcher.

## Upgrading

- Move to Tessera 0.60 when you like. `brock-react` now takes any Tessera from `>=0.58.0 <1` as its peer, so a newer Tessera minor no longer waits for a Brock release. Brock is built and tested on `^0.60.0`, and `brock upgrade` sets the app's catalog to that version.

## New

- Keep a bucket out of the hub switcher. `switcher: false` on a `BucketDef` or in `defineHub` hides its tab. The bucket still opens through its menu entry, its shortcut, a search result and `open('bucket/page')`, and the switcher selects no tab while it is open.
- Let tests answer the folder grant question. `grantFolder: { ask: true, showOnAutomation: true }` shows the native folder question on a plain `--no-focus` launch, and it stays refused on `--review` and `--screenshot` launches. The launch flag `--answer-folder-grants=grant|decline` answers it without a dialog, only on a headless automation launch of an unpackaged app. It grants the same folder a human yes would and does not remember it.

## Fixes

- Stop `brock upgrade` from breaking `pnpm install`. It wrote the Tessera range `>=0.58.0 <1` into `pnpm-workspace.yaml` without quotes, which YAML cannot read. Every catalog writer now quotes a value only when it needs it, and the readers strip the quotes.

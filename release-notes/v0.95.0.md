# Brock v0.95.0

The shell now has landmarks, F6 region cycling and a screen reader announcer, and main-side dialogs can make Enter and Escape land on a safe answer.

## Upgrading

- Expect Tessera `^0.61.0` from `brock upgrade`. Brock is built and tested on it, and the brock grey is lighter so faint and muted text reads at 4.5:1 or more. The `brock-react` peer stays at `>=0.58.0 <1`.

## New

- Move between parts of the window with F6 and Shift+F6. The title bar is a `banner`, the screen host is the one `main`, and toolbars and landmarks are stops too. The keys are the commands `brock.region.next` and `brock.region.previous`, so they show in the shortcut list and can be rebound. Mark an app region with `focusRegion(id, label)`. Focus lands on the control that had it last.
- Speak to screen readers with `announce(message, { politeness? })`. It writes to a polite or an assertive live region that `BrockApp` mounts, and it says the same message again when you repeat it.
- Pick the button Enter lands on in `ctx.dialogs.confirm` with `defaultButton: 'confirm' | 'cancel'`. Escape and closing the box still answer `false`.
- Offer two to four named answers with `ctx.dialogs.choose({ title, message, detail?, choices, defaultId, cancelId, showOnAutomation? })`. It resolves the id picked. Enter picks `defaultId`, and Escape, closing the box and an automation launch resolve `cancelId`.

# Brock v0.96.0

The input module now brings a full Controllers hub under Advanced, with a directory, a live page per pad, logs and guided diagnostics, and any module can contribute a whole bucket.

## Upgrading

- Replace the removed input tester pieces. `InputTester`, `DeviceCard`, `CalibrationPanel` and its types, `ControllerLayout` with `ControllerLayoutProps`, `ControllerLayoutVariant`, `ControllerSlots` and `CONTROLLER_LAYOUT_VARIANTS`, `inputFamilyOf`, `inputTesterScreen` and `INPUT_TESTER_SCREEN_ID` are gone, and so is the `input-tester` screen. Use Tessera's `ControllerSilhouette` or the new `PadOverlay` for a pad drawing. The Advanced entry now opens the `controllers` hub.
- Rename or drop an app bucket with the id `controllers`. The input module owns that id now, and a clash fails at start.
- Run `brock upgrade`. Migration `controllers-bucket` turns each import of a removed name, a `controllers` bucket in `screens.config.ts`, an `input-tester` id and an input module override with `screens: []` into a to-do.
- Move the input module to Tessera 0.60 or later. Its Tessera peer is now `>=0.60.0`. It also depends on `@iconify/react`, `@iconify-icons/lucide` and `@iconify/types`.

## New

- Browse controllers in the Controllers hub. It holds a Directory page (every controller SDL3 knows, searchable, with Rescan), a live page for each connected pad, a Logs page with the connect and disconnect history, and a Diagnostics page with the guided capture wizard, the stick and trigger calibration wizards and the HID byte capture.
- See a pad live. Its page draws the pad with a callout for each input, the sticks and triggers with calibration, the buttons, and the controller facts with rumble tests.
- Add app parts to the pad page. `registerDeviceCardActions` adds icon buttons, such as a Report button, next to Run diagnostics. `registerRumbleTests` adds rumble tests after the module's own. `registerGlyphSource` supplies the button and pad images, which the module does not ship.
- Build a report dialog around the diagnostics wizard with the exported `StepIndicator`, `ReportSection`, `buildReport` and `useDiagnosticsWizardState`.
- Save a debug capture with `writeDebug(name, data)` on the capture API (channel `input:capture:writeDebug`). It writes a JSON file under the data folder's `debug` folder.
- Use the controller input foundation: the SDL family layer, the `controllerInputStore`, the name and family caches, the event log, `padDisplayName` and the controller compounds such as `ControllerStatusBar`. A renderer boot task starts the feed, so nothing runs on import.
- Contribute a whole bucket from a module. `RendererModule.buckets` takes `{ bucket, entries }`. `BrockApp` adds the bucket, its hub and its search entries to the screen tree, and a module menu entry opens it, so it can sit under Advanced with `menu: 'hidden'` and `switcher: false`.
- Keep an element's role with `focusRegion(id, label, { role })`, such as `application` for a canvas.

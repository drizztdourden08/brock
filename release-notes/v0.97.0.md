# Brock v0.97.0

One paragraph for the people who use Brock: what this release changes for them.

## Changes

- The module now owns the whole controller component. `ControllerSilhouette` draws the outline of a pad for an app to put its own marks on, with the same props and the same rendering as the one in Tessera. The module also owns the anchors: `CONTROLLER_SILHOUETTE_ANCHORS` gives `{ x, y, r? }` for each anchor id of each variant, and the values are the ones measured and reviewed in Relic of the Past, so the marks sit closer to the real controls. `PadOverlay`, the pad page and the family overlays read this table. It exports `ControllerSilhouette`, `ControllerSilhouetteProps`, `CONTROLLER_SILHOUETTE_ANCHORS`, `CONTROLLER_SILHOUETTE_ANCHOR_IDS`, `CONTROLLER_SILHOUETTE_VARIANTS`, `CONTROLLER_SILHOUETTE_PATHS`, `CONTROLLER_SILHOUETTE_VIEW_BOX` and the anchor types from `@drizztdourden08/brock-input/renderer`. The outline path data and view box of each variant still come from Tessera. The outline classes are now `controller-outline`. Upgrading: import `ControllerSilhouette` and the anchors from `@drizztdourden08/brock-input/renderer`; Tessera will drop them.

## Fixes

- An app keeps its release notes in the `release-notes/` folder beside its `brock.config.ts`, as the scaffold and the app README say. Before, an app in `apps/desktop` of a workspace had `brock release` and `brock release-notes check` read the repo root instead. Now `brock release`, `brock release-notes check` and the generated workflows all read the app folder (`NOTES_DIR` is `apps/desktop/release-notes`). When the app folder has no `release-notes/` and the repo root has one, they read the root and print one line saying so, so a repo that moved its notes to the root keeps working. The generated workflows follow that choice, so run `brock sync` after moving the notes into the app folder. An app of several keeps its own folder only.
- @drizztdourden08/brock-core@0.97.0
- Brock is built and tested on Tessera ^0.63.0. The peer ranges are unchanged. Tessera 0.62 exports the useInView hook. Tessera 0.63 adds VirtualGrid getRects, section header actions, ActionItem loading, a compact ItemCard tag line, and fixes for the DocumentTabs tablist and the Stepper step names. It removes nothing Brock uses, and the controller silhouette is untouched. - @drizztdourden08/brock-core@0.97.0
- The pad callouts now read better. A callout above or below the pad puts its text at the far end of the underline, away from the leader. The underline is never shorter than five characters, even for a short label such as A or LB. A face button shows the direction it sits in on the pad (Up, Right, Down or Left) on its second line, whatever the family calls the button.

# Brock v0.97.0

The input module now owns the whole controller drawing with measured anchors, pad callouts read better, and release notes are read beside the app.

## Upgrading

- Import `ControllerSilhouette` and its anchors from `@drizztdourden08/brock-input/renderer`. Tessera will drop its copy. The outline classes are now `controller-outline`.
- Expect Tessera `^0.63.0` from `brock upgrade`. Brock is built and tested on it. The peer ranges are unchanged.
- Keep an app's release notes in `release-notes/` beside its `brock.config.ts`. A repo that keeps them at the root still works and prints one line. Run `brock sync` after moving them into the app folder.

## New

- Draw a pad with the module's own `ControllerSilhouette`. It has the same props and rendering as Tessera's. `CONTROLLER_SILHOUETTE_ANCHORS` gives `{ x, y, r? }` for each anchor of each variant, with the values measured and reviewed in Relic of the Past, so marks sit closer to the real controls. `PadOverlay`, the pad page and the family overlays use this table.

## Fixes

- Put the text of a callout above or below the pad at the far end of its underline, and never draw an underline shorter than five characters.
- Show each face button's direction on the pad (Up, Right, Down or Left) as its second line, whatever the family calls the button.
- Read release notes from the app folder in `brock release`, `brock release-notes check` and the generated workflows. Before, an app in `apps/desktop` read the repo root.

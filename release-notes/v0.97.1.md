# Brock v0.97.1

The pad is drawn with Tessera's ControllerSilhouette again, and a visible instance launch now acts like a user launch.

## Upgrading

- Import `ControllerSilhouette`, `ControllerSilhouetteProps`, `CONTROLLER_SILHOUETTE_PATHS` and `CONTROLLER_SILHOUETTE_VIEW_BOX` from `@drizztdourden08/tessera/composites` again. Migration `silhouette-from-tessera` rewrites those imports from `@drizztdourden08/brock-input/renderer`. Brock keeps its measured anchors: `CONTROLLER_SILHOUETTE_ANCHORS` and its ids, variants and types stay in brock-input with the same values.

## Fixes

- Draw the pad with Tessera's component. The component and its outlines are Tessera's, and the input module owns only the anchors and the overlay logic.
- Treat a launch with only `--instance` or `--profile` as a user launch. A visible worktree handover now shows dialogs, asks the folder question, creates the tray, runs start-up prompts and the tour, and keeps LAN discovery on. Hidden launches stay automated through `--no-focus`. A named instance still writes no window state and no last profile.

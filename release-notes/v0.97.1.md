# Brock v0.97.1

One paragraph for the people who use Brock: what this release changes for them.

## Fixes

- The `ControllerSilhouette` component comes from Tessera again, and the module no longer carries a copy of it. Brock keeps the anchors: `CONTROLLER_SILHOUETTE_ANCHORS`, the anchor ids, the variants and the anchor types stay exported from `@drizztdourden08/brock-input/renderer`, with the same positions, and `PadOverlay` and the pad page read them. `ControllerSilhouette`, `ControllerSilhouetteProps`, `CONTROLLER_SILHOUETTE_PATHS` and `CONTROLLER_SILHOUETTE_VIEW_BOX` are no longer exported from the module. Upgrading: import them from `@drizztdourden08/tessera/composites`. The migration `silhouette-from-tessera` rewrites those imports.
- A visible instance launch now acts like a user launch. `--instance` and `--profile` only pick an identity, so a launch with just those no longer counts as an automation launch: `worktree launch <name> none --visible` shows the start-up prompts, the first-run tour, the dialogs and the folder questions, and the window is held on close like any app window. A hidden launch still passes `--no-focus` and stays automated. A named instance still takes no single-instance lock, writes no window state, no last profile and no Linux desktop entry. Upgrading: an app that relied on `--instance` alone to silence prompts must pass `--no-focus` or another automation flag too.

# Brock v0.98.0

An app can place the toolbar host around its own work area, custom setting rows keep their title, and Brock builds on Tessera 0.64 with the version 2 toolbar layout.

## Upgrading

- Expect Tessera `^0.64.0` from `brock upgrade`. Saved toolbar layouts move to version 2 on their own: Brock reads a version 1 layout through `migrateToolbarLayout` and saves version 2 on the next change. An older build that reads version 2 resets its toolbars to the defaults. Read toolbar ids with `toolbarIdsOf` instead of `layout.sides`.

## New

- Place the toolbar host yourself. `BrockApp` takes `toolbarPlacement: 'widgets' | 'app'`. With `'app'` it no longer wraps the widget host, and the app mounts the exported `ToolbarHost` around its own work area. A second host logs one warning and draws no toolbars.
- Keep the title on a custom setting row. A row with `renderControl` keeps its title, description, hint and actions and draws the control in the control slot. `layout: 'wide'` puts a wide editor on its own line below the title, and `chrome: false` gives the old row that the control owns.
- Pass the new `take-corner` dock edit through `WidgetManager`.

## Fixes

- Keep the saved toolbar layout when the toolbar host mounts late. The store emptied it before any toolbar was registered and saved the empty layout.
- Stop on each docked toolbar with F6, even inside the main area.
- Keep a hidden hub home page out of the side nav. It still opens by its route.

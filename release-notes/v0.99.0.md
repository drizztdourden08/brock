# Brock v0.99.0

Widgets can take a bigger share of a docked stack, Brock builds on Tessera 0.65, and worktree refresh no longer trips on files its own setup writes.

## Upgrading

- Expect Tessera `^0.65.0` from `brock upgrade`. It adds toolbar corner take, drop at the pointer with push and PageUp, PageDown, Home and End slot pick. Its toolbar layout is the version 2 one Brock adopted in 0.98.0, so no app change is needed.

## New

- Give a widget a bigger share of its stack with `dockWeight` on its definition or file meta (default 1). A preset row with no `sizes` entry takes the largest `dockWeight` among its widgets, and `sizes` still wins. Docked stacks follow the weights once Tessera takes `dockWeight` in its own release.
- Import `resolveDeviceFromEntry` and `recallControllerSdlType` from the root `@drizztdourden08/brock-input` entry, so a worker with no UI does not pull React and Tessera.

## Fixes

- Let `worktree refresh`, `finish` and `remove` skip the files the worktree setup writes itself (`CLAUDE.md`, `.ai-config.json`, `.mcp.json`, `.brock-port-slot` and `.user-data/`) while they are untracked. A changed tracked file or any other untracked file still blocks.

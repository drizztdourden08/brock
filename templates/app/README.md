# Brock App

A blank Brock app: Electron + React on the Tessera design system, with profiles,
settings and an about screen already in place.

## Commands

```
pnpm install
pnpm dev                 electron-vite dev server and the app, hot reloading
pnpm build               dist/electron, dist/preload, dist/renderer
pnpm start               run the built app
pnpm start:headless      the same, off screen and muted (automation)
pnpm sync                regenerate the managed files after a Brock update
pnpm brock icons         copy the Tessera brand icon set (build runs it first)
pnpm lint                tsc, eslint, stylelint
pnpm lint:md             markdownlint
```

## Layout

```
brock.config.ts          product identity, targets, modules      yours
pnpm-workspace.yaml      the catalog of dependency versions       yours
electron/main.ts         bootstrapApp(product, { modules })       yours
electron/preload.ts      createPreloadBridge({ maps, namespaces }) yours
src/product.ts           defineProduct(config.product)
src/main.tsx             <BrockApp ... />
src/theme.css            Tessera palette seeds
src/settings.type.ts     AppSettings
src/settings.constants.ts  defaults, tabs
src/ipc/contract.type.ts  channel augmentation
src/ipc/contract.constants.ts  the app maps
src/screens/HomeScreen.tsx  the first screen
src/menu.constants.ts    title bar menu
build/icons, build/splash  installer icons and splash, copied from Tessera by brock icons
public/logos/            the app logo, its bot variant and the window icons, written by brock icons
.brock/                  generated by brock sync, do not edit
```

`icons: { brand: 'brock' }` in `brock.config.ts` names the Tessera brand whose files
`brock icons` copies; `build/` and the `public/logos/` files are generated and ignored by
git. The title bar, the about screen and both splash screens show `logos.app`
(`./logos/icon-256.png` by default); a named instance shows `logos.instance`, the bot
variant the same command draws. An app with its own art drops `brand`, sets `ico`,
`png256` and `png512` for the installer and puts its logos in `public/logos/`.

The build writes the splash window page and the boot splash inside `src/index.html` from
the product name, logo and `window.backgroundColor`, so the app ships neither by hand.
A `src/splash.html` of its own replaces the generated one.

`electron.vite.config.ts`, `electron-builder.config.cjs`, `eslint.config.mjs`,
`stylelint.config.mjs`, `.markdownlint-cli2.mjs` and `tsconfig.json` are managed:
`brock sync` rewrites them and `brock check` fails CI when they drift.

Dependency versions are `catalog:` entries resolved from `pnpm-workspace.yaml`; change a
version there and it applies everywhere.

## Adding things

- A screen: `defineScreen({ id, title, render })` in `src/screens/`, then add it to
  `SCREENS` in `src/main.tsx`.
- A setting: a field on `AppSettings`, a default in `DEFAULT_SETTINGS`, a tab or a
  section in `SETTINGS_TABS`.
- An IPC channel: declare it on the contract in `src/ipc/contract.type.ts`, name it in the
  matching map, handle it in main through `bootstrapApp`'s `handlers`. For example
  `'notes:list': () => Promise<string[]>` on `InvokeContract` and
  `listNotes: 'notes:list'` in `APP_INVOKE_MAP`.
- A module: `pnpm brock add updater` (or any package with a `package.json#brock`
  manifest).
